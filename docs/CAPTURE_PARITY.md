上游基准：[mg-chao/snow-shot](https://github.com/mg-chao/snow-shot)（本机 `C:\main\APPS\_refs\snow-shot`，commit `637f8ca`）。
本文是**唯一进度账本**：每个模块一行，标出上游实现位置、LTools 现状、所属批次与状态。
批次完成即改状态并写「验收」记录；跨批次的临时决定写进 §6 变更记录。

## 1. 判定口径

- **1:1 复刻** = 行为（同样输入得到同样的像素 / 文本 / 文件）、交互（手势、快捷键、悬停、拖动、取消路径）、界面（布局、度量、配色、图标）三者都与上游一致；平台差异（Windows 无 macOS 权限引导）只在 §6 记差异，不降级。
- 每批次必须同时满足：构建 0 错 0 警 → `LTools.exe --selftest` 全绿 → 仓库外冒烟（`capture-overlay-smoke` / `record-e2e` 或新 harness）全绿 → 真机点一遍相关路径。
- 纯逻辑（几何 / 命中 / 序列化 / 样式回落）进 `--selftest` 的 `capturePro` 组；需要真窗口 / 真鼠标 / 真编码器的进仓库外 harness。
- 状态：`✅` 已 1:1；`🟡` 有但不等价（缺参数 / 缺交互 / 度量不同）；`❌` 完全没有；`⏳` 本批次进行中。

## 4. 每批次的实施顺序（固定套路）

## 5. 与上游的已知平台差异

| 主题 | 上游 | LTools 处理 |
| --- | --- | --- |
| 权限引导（屏幕录制授权） | macOS TCC 引导页 | 不复刻（Windows 无此权限） |
| 云上传 / AirDrop | 第三方服务 | 不复刻，导出走本地文件 / 剪贴板 |
| 文档识别（富文本模型） | Snow Shot 私有云返回结构化文档 + 图片 / 公式 | 本地按 OCR 版面派生块（标题 / 段落 / 列表 / 表格），无图片与公式；导出格式齐全，内容以识别为准 |
| 在线翻译 | 自带 DeepL / DeepLX / 百度 / 有道，另有私有云的快速翻译（多协议 + 并发 8） | 只留**一个 OpenAI 兼容的 `/chat/completions`**（自建网关 / 代理 / 本地模型都通），密钥与端点存在 `configs/settings.json`；不做多家协议适配（以后要加就加一个 provider 分支，别塞进同一个函数） |
| 译文画进原图（`originalImageTranslation`） | 上游先专用模型「擦掉原文字」得到干净底图，再把译文画上去 | 本地没有文字擦除底图：**原图作底 + 逐行铺估出来的底色盖掉原字 + 用估出的字色画译文**（合并段铺的是段框底色）。观感接近，原字被盖住但底图不是「修复」过的像素；纯文本图（不开原图）是白底 + 行底色 |
| LaTeX 识别与渲染 | 视觉模型认出公式源码，内置 **MicroTeX** 在进程内排版成预览图（`request(source, viewportSize, dpr, fg, bg)`） | 本地**没有** MicroTeX 等价引擎（.NET 侧没有稳定离线的 TeX 排版），所以不做假渲染：LaTeX 页只给公式源码展示与复制（识别仍走 OCR 行，按 `$…$` / `\begin{…}` 特征筛公式行）；真要渲染得接可配端点，与 Markdown / HTML 的「云端视觉模型」同一条口径 |
| PDF 导出 | Qt `QPdfWriter` 进程内渲染 | 走系统自带 Edge / Chrome 的 headless `--print-to-pdf`；**没装浏览器时明确报错**（提示改导 Word / HTML），不假装成功 |
| 主题皮肤 | ant-design-qt 多主题 | 跟随 LTools `Themes/Modern.xaml` 灰阶主题，只复刻度量与交互 |
| 贴图文字 / 颜色卡的富文本 | 上游把剪贴板里的 `text/html` 交给 Qt 富文本排版再渲染成贴图 | 本地没有等价的 HTML 排版引擎，取 `text/plain`（同样的文字、同样的折行度量，但不保留粗斜 / 颜色 / 链接样式）；要富文本得接一个可配端点，与 Markdown / HTML 同一条口径 |
| 拖放 / 批量贴出 HTML·Markdown 文件 | 上游用 `QTextDocument` 把 `.html` / `.md` 排版后渲染成贴图 | 按纯文本贴（内容不丢，样式不保）；`webp` / `jxl` / `avif` 能不能解码取决于系统 WIC，解不出来提示「读不出来」而不是贴一张空图 |
| MCP | 上游自带 MCP 服务 | 由 LTools 自身 MCP（`Core/Ai`）承担，截图 Pro 不另开一套 |
