## 1. 产品形态与主线

| 项 | 内容 |
|---|---|
| 平台 | Windows x64/ARM64、macOS 15+（Apple Silicon / Intel） |
| 版本 | **Snow Shot**（完整）/ **Snow Shot Mini**（无翻译页、二维码、文档识别、LaTeX、云上传、账号；OCR 模型不随包） |
| 常驻形态 | 托盘图标 + 全局快捷键 + 可选悬浮工具栏 + 可选全屏画布 |
| 主窗口 | 左侧导航（220 DIP，可折叠到 80）+ 右侧内容区 + 自绘标题栏 |
| 语言 | 简体中文 / 繁体中文 / English |

四条主线：

1. **截图 + 标注**：冻结屏幕 → 智能选区 / 手框 → 标注 → 复制 / 保存 / 贴图 / 识别 / 翻译 / 滚动截图 / 录屏 / 上传。
2. **固定到屏幕（贴图）**：把截图、剪贴板、文本、文件、实时窗口钉在屏幕上，可缩放 / 半透明 / 锁定 / 分组 / 标注。
3. **屏幕录制**：选区录制 → 控制条 → 裁剪 → MP4 / GIF / APNG / WebP，含鼠标轨迹、按键显示、摄像头。
4. **图像工具**：图像拼接（含 PDF 模板）、图像分割、图像编辑窗口；配套截图历史与固定到屏幕管理两个资料库。

## 3. 截图主流程（状态机）

```
待机 ──F1 / 快捷键 / 托盘──> 智能选择预演（悬停即高亮窗口或控件）
   ├─单击 ────────────────> 选区确认（编辑态）
   ├─拖动 ────────────────> 手动框选 ──松手──> 选区确认（编辑态）
编辑态 ──点工具──> 标注（可连续画）──Esc/再点选择──> 编辑态
编辑态 ──Enter/Ctrl+C──> 复制并关闭
编辑态 ──Ctrl+F / 中键──> 固定到屏幕
编辑态 ──Ctrl+D / Ctrl+T / Ctrl+X / Ctrl+Q──> 识别 / 翻译 / 表格 / 二维码
编辑态 ──L──> 滚动截图     编辑态 ──Ctrl+R──> 录屏
编辑态 ──Esc──> 取消（可配置二次确认）
```

关键事实：

- **智能选择是默认态**：不用按下，悬停就按「窗口 z 序 + 命中元素」预演一个候选矩形；单击确认，按下后位移超过系统拖拽阈值则转手动框选。
- **滚轮在智能选择态切换层级**（由最深子元素逐级退到外层窗口），`Tab` 在「整个窗口 / 窗口子元素」之间切换目标。
- **工具条类快捷键（L / Ctrl+D / Ctrl+S / Ctrl+F…）在选择中也能用**：会先把当前选区确认掉再执行（`screenshotoverlayinputhandler.cpp:1277-1301`）。
- **Enter 双绑定**：选择中 = 确认选区；已确认后 = 复制（优先级：WindowCommand 400 > ScreenshotShortcut 300）。
- **Esc 在按键抬起时生效**（Release），避免误触；取消是否弹确认由设置决定。
- 最小选区 1px，小于即视为失败、不确认。
- 选区遮罩默认 `#00000080`；圆角上限 256、阴影上限 64。

## 4. 截图覆盖层 UI 布局

从下到上四层：**冻结画面 → 压暗遮罩 + 选区挖洞 → 标注层 → 窗口层（手柄 / 信息条 / 动作栏 / 工具面板 / 提示条）**。

### 4.1 选区与手柄

- 8 个方向手柄（4 角 + 4 边），命中容差 **8 画布单位**；命中内部 = 整体移动。
- 圆角 / 阴影小控件命中半径 12（`8 × 1.5`）。
- 多区域选区时：在某区域内部拖动 = 移动该区域；点击选区外 = 清空重框。
- 区域类型四种：**矩形 → 折线 → 曲线 → 自由绘制**，`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换。
  - 折线 / 曲线：单击逐点加，**双击结束**（≥3 点自动闭合），`Backspace` 删最后一点。
  - 自由绘制：按下拖动、松手结束；曲线与自由绘制都做 Catmull-Rom 平滑。
- 加区 / 减区是独立按钮（Move 工具族里），做一次布尔运算，结果可坍缩成单矩形。

### 4.2 尺寸 / 坐标信息条

- 位置依次尝试：**左上 → 右侧 → 左侧 → 下方**，间距 4，都放不下就夹进屏幕（`screenshotgeometry.cpp:1108-1137`）。
- 两种模式：
  - 智能选择阶段 = **只读尺寸**（宽 × 高 px）；
  - 确认后 = **完整模式**：X, Y + 锁定比例图标 + 宽×高 + 比例下拉 + 圆角 / 阴影控件。

### 4.3 完成动作栏（选区下方工具条）

- 定位：**右对齐选区右下角、下方 gap 4**；下方放不下翻到上方；仍越界水平夹取（`screenshotgeometry.cpp:1139-1216`）。
- 默认分组（`screenshottoolbarlayoutmodel.h:476-492`，同组折叠成一个触发按钮，点开是横向弹层）：

| 组 | 内容 |
|---|---|
| 1 | 转 HTML · 转 Markdown · LaTeX 公式识别 · 条码识别 · 文档识别 · 表格识别 |
| 2 | 录制屏幕 |
| 3 | 固定窗口到屏幕 · 固定到屏幕 |
| 4 | 文本识别 |
| 5 | 文本翻译 |
| 6 | 滚动截图 |
| 7 | 上传到云端 · 隔空投送 · 打印 · 快速保存 · 保存为文件 |
| 8 | 分隔符 |
| 9 | 取消截图 |
| 10 | 复制 |

- **没有「按宽度自动溢出折叠」**：按钮多了靠「同组堆叠 + 用户在设置里重排/合并」解决。
- 智能选择阶段不显示这条栏；`截图界面 › 隐藏选区工具栏` 可整体关掉。

### 4.4 标注工具面板

- 位置与动作栏同一套锚定规则（选区右下、gap 4，越界翻转/夹取）。
- **两行结构**：主行 = 工具按钮；下面一行 = 当前工具的参数（颜色、线宽、字号、箭头样式…），随工具切换。
- 尺寸常量：按钮 32、图标 24、拖柄宽 18（图标 18）、分隔线 1×16、水平内边距 12、上下 4。
- 拖柄可拖动面板（`SizeAll` 光标）；**双击拖柄不复位**。
- 紧凑布局开关：可调「布局间距」（滚轮 ±5，点击复位 0）与「背景不透明度」（滚轮 ±10%，点击复位 0%）。

### 4.5 快捷键提示条

- 屏幕**左下角**，外边距 16；黑底 64% 不透明、圆角 6、白字 14px，按键用圆角 chip。
- 文案按模式切换：`智能选择 / 选区 / 工具 / 滚动截图` 四套（`screenshotshortcuthints.h:236-544`）。
- **与选区相交、或光标进入时自动隐藏**（避免挡内容）。

### 4.6 其它辅助

- 辅助线：按住 `Alt`（可设「点按」）显示对齐辅助线；颜色可配、可「与背景相近时自动反色」。
- 取色器：显示模式三选（移出选区时隐藏 / 始终显示 / 始终隐藏）；坐标全局或相对；颜色格式 4 种循环（`Shift` 单击切换）。
- 区域类型提示：可在截图窗口顶部显示当前区域类型。
- 光标：默认不显示；`` ` `` 切换；可设置是否入画。

### 5.3 颜色与尺寸预设

- 描边 5 色：`#F5222D` `#52C41A` `#1677FF` `#FADB14` `#000000`
- 填充 5 色：透明 / `#FFCCC7` / `#D9F7BE` / `#BAE0FF` / `#FFF1B8`
- 高亮 5 色：`#FF7875` / `#D3F261` / `#69B1FF` / `#FFF566` / `#B37FEB`
- 每组固定 5 个，可在设置里改。
- 线宽预设 2 / 4 / 8；字号 S/M/L/XL = 24 / 30 / 42 / 54；水印字号 12 / 16 / 24 / 30。
- 线宽上限 72、圆角 0–83。
- 参数行里的「小数字按钮」= 复位（放大倍率 2.0、端点比例 1.0、水印角度 30°、间距 56、布局间距 0、背景不透明度 0%）。

### 5.4 标注模板

- 保存的是**当前选中元素的完整集合**（含各自样式）+ 版本号 + 包围盒中心，不是「样式预设」。
- 插入时整体平移、重映射 id 与绑定关系，然后选中新元素；插入点是选区中心。
- 存在配置里（`drawing/draw_templates`，`name` + base64 `payload`）；UI 是模板下拉 + 「添加模板…」「删除模板」，空态「暂无模板 / 没有匹配的模板」。

## 6. 工具面板的堆叠与自定义

- **堆叠**：同一「位置」放多个工具时，只显示最下面那个作为触发按钮；悬停/点击在**上方**弹出横向弹层选同组其它工具。设置里自顶向下存，最底部 = 主行按钮，弹层顺序反转。
- 选中组内其它工具后触发按钮图标跟着换，除非开「保持显示分组主按钮」。
- **隐藏**：工具可拖到「隐藏的工具」区，不再显示。
- **布局编辑器**（设置 › 截图 / 固定到屏幕 / 录屏 / 悬浮工具栏，共 5 个）：上方预览 + 底部 56px 隐藏区；拖到工具旁边 = 新建位置、拖到工具上方 = 堆叠、分隔符独占位置。
- 截图、贴图、录屏、悬浮四条工具条各自独立配置。

## 8. 固定到屏幕（贴图）

### 8.1 出场

- 来源 5 类：截图 / 截图历史 / 剪贴板 / 选中的文件 / 其它（旧版）。
- 截图来源按选区 **1:1 落位**；剪贴板与文本来源优先复现有保存的位置尺寸，否则适配工作区并居中；`自动调整窗口大小` 默认开且**只缩不放**。
- 新窗口加入当前活动分组，激活即提到同级最前并持久化顺序。
- **重复贴同一内容**默认「摇动窗口」（300ms、±6px），可改为恢复上次关闭窗口 / 重复执行 / 无。

### 8.2 鼠标交互

| 操作 | 行为 |
|---|---|
| 左键拖动 | 移动窗口；锁定态拖动被吞并提示「已锁定」 |
| 边缘 / 角落拖动 | 8 向缩放，**10%–500%** |
| 右键按下拖动 | 框选裁剪区，松手即应用；位移 <10px 视为右键菜单；`Esc`/滚轮/其它按下取消 |
| 滚轮 | 按「滚轮缩放步长」（默认 10）缩放；锚点默认鼠标位置（可选左上/右上/左下/右下/居中） |
| `Ctrl`+滚轮 | 不透明度，步长默认 5，范围 **25%–100%** |
| 双击 | 默认「缩略图模式」（83px 方块、鼠标为锚、150ms 动画） |
| 中键 | 默认「重置缩放」 |
| 悬停 | 右上角出现「标注」「关闭」按钮；进入即显、离开 100ms 隐藏；缩略图/标注/穿透态或窗口过小时不显示 |
| 摇动窗口 | 快速来回拖：同组有隐藏贴图则显示它们，否则隐藏其它贴图并 toast |
| `Ctrl`+单击 | 多选；`Ctrl`+拖动 = 拖出为文件；多选可成组移动/缩放/对齐 |
| 鼠标穿透 | 切换后事件穿到底层窗口 |
| 贴顶隐藏 | 顶部手柄 30×6、2px 描边、250ms 动画；指针进入展开、离开收起 |

### 8.3 右键菜单（固定宽 300）

1. 复制到剪贴板 / 复制原始内容 / 另存为文件 / 转为图像（仅实时窗口）/ 隔空投送（macOS）
2. 文字识别（勾选项）+ 文字类型子菜单（识别结果 / 翻译结果）
3. 标注模式（静态图）；动图换成 播放·暂停 / 上一帧 / 下一帧 / 播放速度
4. 处理图像子菜单：不透明度（±10%、25/50/75/100）、缩放（±10%、百分比档）、顺时针/逆时针旋转、水平/垂直翻转、重置变换、图像拆分、图像编辑
5. 应用裁剪（有裁剪区时可用）
6. 分组子菜单（每项带 `非忽略/总数` 徽标、新建分组、删除空分组、删除指定分组）
7. 缩略图模式 / 贴顶隐藏 / 鼠标穿透 / 锁定模式
8. 固定到屏幕管理子菜单：始终置顶 / 显示边框 / 显示阴影 / 批量操作 / 加载新内容 / 显示所有窗口 / 隐藏其他窗口 / 关闭其他窗口 / 关闭所有窗口
9. 显示主界面（托盘不可用时）/ 关闭 / 销毁

批量子菜单：全选、拼接图像、复制文件到剪贴板、另存为 → 启用/禁用 缩略图·贴顶隐藏·锁定 → 关闭 / 销毁 → 「当前 N 个窗口」。

### 8.4 标注模式

- 进入：菜单或 `Space`；进入后原生拖动/缩放被抑制，画布接管。
- 工具条浮在窗口上：移动（调整窗口）/ 选择 / 图形 / 气泡 / 箭头 / 直线 / 距离 / 角度 / 括号 / 画笔 / 高亮 / 聚光灯 / 放大镜 / 橡皮擦 / 滤镜 / 水印 / 文本 / 序号 / OCR / 翻译 / 表格 / 二维码 / 图像转换 + 撤销重做 / 复制 / 保存 / 确认。
- 退出：再点菜单、`Space` 或「确认」；标注结果写回当前内容，参与裁剪 / 另存。
- 「关闭前退出标注模式」默认关。

### 8.5 文本贴图与实时贴图

**文本贴图**：内边距 16、默认字号 16、最大宽 1024；超宽换行不裁剪；颜色值渲染成色卡（HEX/RGB/HSL/RGBA/HSLA）；可「复制原始内容」（原文/HTML）；选中文字可快速标注（复制文本 / 高亮 / 波浪线 / 下划线 / 删除线）。

**实时贴图**：从选区里的窗口取实时画面（`Alt+W`）；显示源窗口状态（最小化 / 已关闭 / 不可用）；源窗口关掉贴图自动关闭；不进管理页、不可标注/分组；可「转为图像」定格当前帧。

### 8.6 分组与管理页

- 内置 `default` 组不可删；组名 ≤16 字符、忽略大小写去重、最多 128 组。
- 切组 = 关闭非活动组的窗口并恢复活动组的；切换有「按住快捷键循环、松手确认」的居中弹层（默认未绑定）。
- 管理页：来源筛选 + 日期范围 + 分页（10/20/50）；卡片显示「未关闭 / 已隐藏 / 已关闭」，行内 显示|恢复 / 删除 / 更多（拼接、拆分、编辑、复制路径、在文件夹中显示）；批量：全选本页、删除所选、拼接、固定。
- 已关闭记录：默认保留 7 天 / 100 条 / 1024 MiB，可选永久保留。

### 8.7 外观与默认值

- 边框默认开（1 物理像素）：普通 `#DBDBDB`、激活 `#69B1FF`、锁定 `#FAAD14`。
- 阴影默认关（Windows 预留 16 物理像素）：普通 `#BFBFBF`、激活/锁定同上。
- 其它默认：显示窗口按钮开、摇动隐藏开、关闭确认关、销毁确认开、自动识别文本开（Mini 关）、识别结果可选文本「始终」、重复内容 = 抖动、自动调整大小开。
- 快捷键默认：`Ctrl+C` 复制、`Ctrl+Shift+C` 复制原始、`Ctrl+S` 另存、`Ctrl+P` 打印、`Ctrl+D` 识别结果、`Space` 标注、`M` 调整窗口、`R` 缩略图、`H` 贴顶隐藏、`Ctrl+M` 穿透、`L` 锁定、`T` 置顶、`B` 边框、`Y` 阴影、`Esc` 关闭、`Shift+Esc` 销毁、`]`/`[` 不透明度、`.`/`,` 缩放、`3`/`4` 翻转、`0` 重置变换。

## 9. 识别与翻译

### 9.1 文本识别结果窗口

- 两种呈现：嵌在覆盖层选区里，或独立顶层窗口。
- 内部是一个 `QStackedLayout`，6 层互切：**OCR 文本 / 纯文本编辑 / 表格编辑 / 图片转换 / 二维码浏览器 / 格式化文档（Markdown·HTML·LaTeX）**。
- 快捷键：`Esc` 关闭、`Ctrl+C` 复制当前可见内容、`Ctrl+A` 全选（编辑态）。
- 右键菜单：复制 / 全选 / 翻译 / 显示原图 / 保存结果 / 关闭。
- 进度文案分阶段：「正在准备文本识别组件(%1%)」「正在识别文本/表格/条码/文档/LaTeX 公式」；>4K 直接拒绝。
- 表格页是可编辑表格（合并/拆分单元格），复制出 TSV。

### 9.2 翻译

三条入口：

| 入口 | 形态 |
|---|---|
| 截图内翻译 | 工具面板给「文本翻译 / 显示原图 / 目标语言 / 翻译服务 / 翻译设置」；两种展示：**原图翻译**（译文覆盖在图上）与**文本编辑** |
| 独立翻译页 | 源语言 / 目标语言 / 服务三下拉 + 原文/译文双栏；`Ctrl+C` 复制、`Ctrl+Q` 关闭；560px 断点切单栏 |
| 独立翻译窗口 | 720×500、最小 650×400、记忆几何 |

- 截图翻译设置对话框（宽 440）：目标语言、次要目标语言、服务、模型、置信度 30–100、原图翻译开关。
- 默认：源语言 `auto`、次要目标 `en`、置信度 60、排版「智能合并」。
- 译文同步阈值 8 行 / 512 字。

### 9.3 二维码 / 条码

- 识别后在画布上按位置画圆形编号标记；点标记弹气泡：「复制文本」「打开链接」。
- 无结果只提示「未识别到条码」，不算失败。

### 9.4 OCR 模型与性能

6 项设置：模型类型（超小型 / 小型 / 中型 V6，默认小型）、文字检测缩放（限制长边 / 放大短边）、文字检测处理（准确优先 / 速度优先）、硬件加速（默认关）、常驻识别进程（普通版默认开）、模型热启动（默认关，需常驻）。
常驻进程 1 分钟内崩 3 次会暂停并退避重试。

## 10. 滚动截图

## 11. 屏幕录制

### 11.1 流程

1. 入口：快捷键 / 工具栏 / 托盘 / 从截图选区直接开录（选区转成录制区域）。
2. 区域：可拖移、8 向缩放；「跟随鼠标」时叠层跟随光标所在屏；可选倒计时 1–10 秒。
3. 录制中控制条：贴选区右下或右上（间距 4），可自动隐藏（边缘标签，悬停 100ms 展开、离开 200ms 收起、50ms 轮询）。
4. 状态提示：格式（MP4/GIF/WebP）+ 麦克风开关 + 系统音频开关。
5. 结束：保存到配置目录（或另存）、可选复制文件到剪贴板、可选自动退出、系统通知（点通知定位文件）。

### 11.2 控制条按钮（默认顺序）

开始/停止 → 暂停/继续 → 时长 → 麦克风 → 系统音频 → 分隔 → 打开文件夹 → 关闭 → 裁剪 → 保存 → 复制。

- 状态机：待机显「开始」；录制中显「停止」+「暂停」；暂停显「继续」。
- 动图格式（GIF/APNG/WebP）下音频按钮禁用并提示「动画录制格式不包含音频」。
- 裁剪面板打开时其它按钮禁用。

### 11.3 参数

| 组 | 项 |
|---|---|
| 视频与音频 | 清晰度 4K/2K/1080p/720p/480p、帧率 5/10/15/24/30/60/83/120、视频质量 0–100（默认 80）、独立音轨、麦克风增益 −24…+24 dB（带电平） |
| 动图 | 动图清晰度（无 4K/2K）、帧率 5/10/15/24、循环播放 |
| 编码 | 编码器 H.264/H.265（含硬件变体）、预设 ultrafast→placebo（默认 veryfast） |
| 录制内容 | 录制时捕获工具栏、录制捕获 API（自动/DXGI/WGC/GDI） |
| 效果 | 鼠标轨迹色+时长 100–2000ms、点击色、显示光标、显示按键（高亮/点击/滚轮、数字/字母/控制键/保留快捷键）、键盘尺寸 32–128 与前景背景色、高亮半径 8–128、跟随鼠标（平滑/减少抖动）、摄像头（50–500px、方/圆）、后处理（进度条/播放时间 + 颜色） |
| 操作方式 | 自动隐藏工具栏、录制结束后自动退出、导出完成后通知、关闭录制时删除文件、显示录制状态提示 |

### 11.4 裁剪（trim）

工具条 480 宽：重播、播放/暂停、速度 0.25×–3.0×、时间轴轨道 + 起止双手柄（tooltip 带时间码）；16ms 轮询刷新预览；导出走「另存为」、禁止覆盖源文件；全段未改动时直接复用源文件。

### 11.5 快捷键默认

`Ctrl+S` 开始/停止、`Ctrl+E` 导出、`Ctrl+C` 复制、`Esc` 结束、`R` / `Shift+R` 上/下一个录制区域。

## 12. 图像拼接 / 分割 / 图像编辑

### 12.1 拼接（Collage）

- 模型：方向（纵向 / 横向 / 自定义）、尺寸（统一 / 原始）、外边框、间距、背景色、行列数；输出静态图或 PDF。
- PDF：纸张 A3/A4/A5/B5/Letter/Legal/自定义/图像尺寸、横竖、合并或分页、页式或模板式、9 种模板（含身份证版式）、页边距与图片间距（mm）、质量 0–100。
- 编辑器：顶部输出类型分段 + 方向三段 + 行列 + 尺寸 + 边框间距（px/%）+ 背景色 8 预设 + PDF 设置组；中间缩略图条 + 预览画布（画布工具条：反序 / 添加 / 适应画布 / 清空）；单元格工具条（顺/逆时针 90°、水平/垂直翻转、重置、替换）；缩略图悬停显示替换/删除。
- 底部：取消 / 图像编辑 / 复制 / 保存；关闭前丢弃确认。

### 12.2 分割（Split）

- 窗口默认 1200×800、最小 900×600、非模态置顶。
- 左预览画布 + 右 340 设置栏：方向（垂直/水平/网格）、类型（智能/等分/精确）、重叠宽度、数量/行/列、尺寸（像素/百分比）。
- 画布交互：中键平移、滚轮缩放、点标尺加分割线、拖线移动、`Delete` 删除、`Esc` 取消拖动；画布底部 撤销/重做/适应画布/重新加载。
- 页脚：输出尺寸 × 张数 + 取消 / 拼成 PDF / 全部保存；保存到 `<目录>/Split Images_<图片名>/1.png…`。

### 12.3 图像编辑窗口

- 非模态、置顶、任务栏可见、可最小化/最大化；多图各自开一窗；空态「添加图像开始编辑」。
- 工具条复用截图标注工具（移动=平移、带裁剪工具、动作按钮只留复制与固定）。
- 底部居中缩放条：适应窗口 / 100%。
- 导出：复制、固定到屏幕、保存、快速保存、打印、上传云端。
- 关闭前「放弃更改？/ 继续编辑」。

## 13. 悬浮工具栏 / 全屏画布 / 托盘

### 13.1 悬浮工具栏

- 两种形态：**图标模式**（雪花 48px）/ **工具条模式**（32px），带阴影。
- 图标模式点击 = 截图（macOS 展开工具条）；悬停 100ms 展开、离开 200ms 收起。
- 右键菜单：图标模式/工具栏模式、自定义工具栏、全屏时隐藏、截图时隐藏、关闭。
- 拖动移动 + 边缘吸附停靠；位置按显示器 EDID 记忆。
- 不透明度：空闲默认 50%，悬停/拖放/菜单展开时 100%。
- **拖放**：拖入文件按 `拖放行为` 分派（默认固定到屏幕，另有图像拼接 / 分割 / 编辑）；拖放就绪显示绿光。
- 溢出项收进「⋯」；默认关闭（`enabled=false`）。

### 13.2 全屏画布

- 全屏透明窗口 + 右下角（内缩 15px）浮动工具条。
- 点击穿透可切换；穿透时 50ms 轮询并把工具条不透明度降到 0.32。
- 支持激光笔；`Esc` 退出。

### 13.3 托盘

- 每次弹出重建菜单，最小宽 300；分组：截图 → 固定到屏幕 → 屏幕录制 → 其他 → 系统（窗口分组 / 显示主界面 / 重启 / 退出）。
- 默认菜单项约 30 条（与设置里的「托盘菜单」勾选项一一对应），右侧显示快捷键。
- 左键单击默认 = 截图；中键默认 = 截取焦点窗口；右键 = 弹菜单。
- 图标：默认/浅色/深色/雪球系列 + 自定义；禁用全局快捷键或全屏抑制时叠角标。
- 可整体关闭托盘。
