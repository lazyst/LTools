# INFO_HELPER.md · 辅助工具（取值卡）

**一句话**：托盘「辅助工具…」打开的窗口，把窗口 / 屏幕区域 / 坐标 / 取色 / 屏幕环境 / 截图 / 选中的文件
取成一张张**取值卡**，复制成文本贴给 agent 写动作。它不是动作，也不是取值动作单元。

术语（辅助工具 / 取值卡）见 `CONTEXT.md`；实现约束与踩过的坑见 `AGENTS.md` 的「辅助工具」条。

## 为什么要它

写动作最费劲的一段是「把屏幕上的东西抄成参数」：窗口标题 / 类名 / 进程名、一块区域的 `x,y,w,h`、
一个按钮的坐标、一个颜色值。以前只能靠截图 + 肉眼估、或者先照着 `ltools_health` 自己算。
辅助工具把这些取成**一段能直接粘进对话的文本**，单位统一、格式统一，agent 不用再猜。

范围之外（明确不做）：

- 不读控件树（UIA）。要控件名与精确矩形用 MCP 的 `ltools_uia_tree`。
- 不录按键 / 鼠标手势（宏已经有录制）。
- **卡片不落盘**：不新增配置域、不进备份、不进知识包、不进 MCP 工具面。

## 入口与窗口

- 托盘右键 →「辅助工具…」（设置那一组里）。**单实例**：再点一次只是激活 / 还原已开的窗口。
- 720×640，可缩放；`WindowSizing.Mode="Dialog"`（尺寸与位置按所在显示器工作区夹取）。
- 三行结构：标题栏 36 / 头部工具区（Auto）/ 卡片列表（`*`），底部一条状态栏 + 页面操作。
  **不用 `DialogShell`**：它的内容整体在一个 `ScrollViewer` 里，工具条会跟着卡片滚走。

头部：

```
坐标与矩形都是虚拟桌面物理像素（多屏时可能为负），与截图、找图、鼠标注入同一套坐标。

[ 窗口信息 ]        [ 屏幕区域 ]        [ 屏幕坐标 ]
 标题·类名·进程·矩形   框选·x,y,w,h      单击取点·x,y

[屏幕取色] [屏幕环境] [截图 ▾] [选中的文件]
```

- 三个**取值方块**（大按钮）：窗口信息 / 屏幕区域 / 屏幕坐标。
- 四个 **chip**：屏幕取色 / 屏幕环境 / 截图（下拉三种：整个屏幕 / 框选区域 / 选一个窗口）/ 选中的文件。
- 底部：状态行（3 秒后回到默认提示，失败保持红色不改回）+「复制全部」「清空」。
  没有卡片时这两个按钮置灰，列表中间显示空态文案。

每张取值卡：标题 + **正文**（一个只读多行文本框，等宽、无边框、贴一层浅灰底）+ 截图卡的缩略图，
右侧三个小图标 `↻` 再取 / `⧉` 复制 / `✕` 删除。图标按钮用 `CommandParameter` 认卡片
（`BtnGhost` 把 `Tag` 当悬停底色，不能用 `Tag` 传值）。

**正文就是复制文本**：显示的是 `InfoCard.Text`，`⧉` 复制的也是它；一条信息一行（`标签：值`），
所以可以自己划选、Ctrl+C 只复制挑中的那几行（比如 14 条路径里只挑 2 条）。
这也是为什么卡片不再有「只画前 N 条」—— 画少了你也就选不到。

最新取的卡插在**最上面**，不用往下翻。

## 取值与卡片内容

所有坐标、矩形都是**虚拟桌面物理像素**（与截图、找图、鼠标注入同一套坐标系；多屏时 `x` / `y` 可能为负）。
复制文本的抬头会写明这一点。

| 取值 | 怎么取 | 正文（一条信息一行，可直接划选） | 示例 |
| --- | --- | --- | --- |
| 窗口信息 | 点选器选一个窗口 | 标题 / 类名 / 进程 / 矩形 / 客户区 / 状态 / 句柄 | `窗口信息（坐标与矩形是虚拟桌面物理像素）` + `标题：…` `类名：…` 各行 |
| 屏幕区域 | 框选 | 矩形 / 区域参数 | `屏幕区域（虚拟桌面物理像素；…）`、`矩形：x=.., y=.., w=.., h=..`、`区域参数：x,y,w,h` |
| 屏幕坐标 | 单击取点 | 一行 `x=.., y=..` | `屏幕坐标（虚拟桌面物理像素）`、`x=.., y=..` |
| 屏幕取色 | 单击取色（带放大镜） | 坐标 / 颜色 / RGB | `坐标：x=.., y=..`、`颜色：#RRGGBB`、`RGB：r=.., g=.., b=..` |
| 屏幕环境 | 直接读 | 虚拟桌面 / 光标 / 每块显示器 | 虚拟桌面矩形、光标位置、每块屏「矩形 · 工作区 · 缩放%」 |
| 截图 | 整个屏幕 / 框选区域 / 选一个窗口 | 方式 / 文件 / 区域（+ 缩略图） | `截图（整个屏幕）`、`文件：<绝对路径>`、`区域：…` |
| 选中的文件 | 读资源管理器 / 桌面 | 文件夹 + **全量路径**（一条一行） | `文件夹：…` + 每条路径一行，可以只挑几行复制 |

细节：

- **窗口的「进程」带 `.exe`**（`notepad.exe`）：作用范围名单写的就是这个名字。
- **客户区**已用 `ClientToScreen` 换算成屏幕坐标，可直接当点击坐标用。
- **区域参数**是逗号串（`100,200,640,480`），「固定区域」类参数直接填。
- **选中的文件**不看前台窗口（辅助工具自己就是前台）：按 z 序找第一个**确实有选中项**的资源管理器
  窗口，都没有就退回桌面选中项（UIA 读图标名后映射回文件）。拿不到就是「没有读到选中的项」，不是错误。
- **截图**落 `cache/info-helper/shot-<yyyyMMdd-HHmmss-fff>.png`，**卡片给完整绝对路径**，
  只保留最近 30 张（`InfoShotStore.Cleanup`）。截图与框选期间 LTools 的窗口会临时最小化，
  所以画面里不会有辅助工具自己；「截一个窗口」点选完会再收一次窗口才截。

## 选中与复制

卡片正文是**只读文本框**，不是画出来的文字：

- 鼠标拖过就选中，`Ctrl+C` 复制挑中的那几行；`Ctrl+A` 全选当前这一张卡。
- 常用：14 条路径里只挑 2 条、只要「矩形」那一行、只把「类名」贴进参数。
- `⧉` 复制整张卡（与正文完全一致），底栏「复制全部」按列表顺序拼所有卡。
- 只读是硬的：选得中、改不了（不会一不小心把取到的值改掉，就没有「改坏了」这种状态）。

正文用等宽字体，一条信息一行（`标签：值`）；所以**不要再给卡片另写一套「两列渲染」**——
显示与复制必须是同一段文本，否则你会看到「选中的和复制的不一样」。

## 再取

`↻` 按卡片自己的参数重取一次：

- **窗口**：用原句柄刷新（窗口关了 → 提示重新取）。
- **截图**：按原矩形重截，旧 png 删掉、写新文件。
- **屏幕环境 / 选中的文件**：直接重读。
- **区域 / 坐标 / 取色**：原值没法复原（那是一次性的交互），重新框 / 点一次。

## 删除与清空

- `✕` 删一张卡；截图卡会顺手删掉自己的 png（只动 `cache/info-helper/` 下的文件）。
- 「清空」先走 `ConfirmDialog`（危险动作，红按钮），确认后连截图文件一起删。
- **关窗口不删截图**：卡片清空，但 png 留在磁盘上——常见用法是「复制路径贴给 agent，然后关掉窗口」。

## 校验

- `LTools.exe --selftest --filter infoHelper`：文案格式（矩形 / 区域参数 / 点 / 颜色 / 状态 / 缩放 / 句柄）、
  七种卡片正文的「一条信息一行」形状与标题、颜色解析的非法值、14 条路径一条不落（不截断才能挑行）。
- 仓库外 `%TEMP%\opencode\info-helper-smoke`（反射驱动 `LTools.dll`）：方块与 chip 的顺序与几何、
  空态与按钮置灰、正文只读且 `SelectAll` 选得中、能只选中一行、三个图标按钮、缩略图、单实例开关，
  并渲染 png 供人眼看。
- 真机点一遍：托盘打开 → 窗口信息 / 框选 / 取点 / 取色 / 屏幕环境 / 三种截图 / 选中的文件 →
  在卡片正文里拖选几行 Ctrl+C，贴进编辑器参数里验证。
