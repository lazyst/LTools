# 超级面板重构：动作面板 + 面板管理

> 参考 Quicker 2.0 的动作面板。本文记录已确认的决策、面板规格、数据模型、
> 匹配规则、设置页结构、迁移方式与落地阶段。改动实现时以本文为准，
> 实现若偏离，先改本文再改代码。

## 0. 目标与边界

**做什么**

- 把超级面板从「4×4 分页格子」重构为上下双区的动作面板：
  - **全局区**：与前台窗口无关，可有多套场景（标签切换）。
  - **上下文区**：跟随**唤起时的目标窗口**（长按右键 = 光标下的窗口，键盘 = 前台窗口），按进程 / 窗口条件自动选择场景；未配置时显示创建提示。
- 设置里新增「面板管理」：管理两个区的场景、分组、动作入口。
- 设置里「动作管理」改成 Quicker 风格的表格，并显示每个动作被哪个区 / 场景 / 分组引用。

**不做什么（明确排除）**

- 不做底部「最近使用」动作条。
- 不做左侧截图、AI 相关的功能。
- 不做「页」：页在迁移时变成全局场景下的分组。
- 不引入 WebView / React；继续用 WPF 原生控件。

## 1. 已确认的决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | 面板分区 | 上下双区：全局区在上，上下文区在下，各占 50%，最小高度 90px |
| 2 | 上下文匹配条件 | 进程（exe / 完整路径）+ 窗口条件（标题包含 / 类名精确） |
| 3 | 全局区组织 | 多套全局场景，用标签切换；每套场景内再分组 |
| 4 | 搜索 | 输入即搜索，打开面板后搜索框默认聚焦 |
| 5 | 「页」的去向 | 取消页概念，旧页迁移为全局「默认」场景下的分组 |
| 6 | 设置结构 | 左侧场景树 + 右侧分组 / 动作 + 动作表引用列 |

补充决策：

- 面板尺寸默认 **560×620**，可缩放，关闭时记忆。
- 唤起位置：**以光标为中心**展开（鼠标落在面板正中）；面板超出工作区时整体平移夹回工作区。
- 上下文只在**面板唤起那一刻**解析；钉住期间不跟随前台变化。锁定只作用于当前会话。
- 删除动作前先列出引用位置；被引用但已不存在的动作在面板上显示为「缺失」磁贴。
- 迁移不弹窗、不打断启动；用户配置不可解析时绝不回写（沿用 `ConfigIO` 的 `LoadStrict` 语义）。
- 设置导航项「超级面板」改名为「面板管理」，`Tag` 仍为 `superpanel`；它带下拉二级页（常规 / 场景 / 禁止弹出），`LastNavPage` 存二级页 `Tag`，旧值 `superpanel` 仍可恢复到常规。

## 2. 面板规格

### 2.1 尺寸与布局

| 部件 | 规格 |
|---|---|
| 窗口 | 默认 560×620 DIP，最小 360×340；可缩放；`WindowStyle=None` + `WindowChrome` 边缘缩放 |
| 左栏 | 宽 44px；顶部 logo 区 44×44；竖排入口 34×34 |
| 顶栏 | 高 36px；左边「LTools」文字，右边搜索框 + 设置 + 钉住 + 关闭 |
| 搜索框 | 200×24，圆角 12，`SurfaceAlt` 底色；默认聚焦 |
| 区头 | 高 24px；**靠左**的场景标签条（横向排列，可横向滚动），无「全局 / 上下文」文字标签 |
| 区域 | 上下两区按比例分高（默认各 50%，`MinHeight=96`），中间 6px 分割条可拖动；比例记入 `Preferences.GlobalRatio`（0.15–0.85） |
| 磁贴 | 最小宽 72，按可用宽度均分（`minmax(72,1fr)`）；横向 gap 4，纵向 gap 2；**透明底、无卡片边框**，圆角 8，仅 hover 时出现软底（照 Quicker） |
| 磁贴内容 | 图标 chip 36px（淡底 + 1px 内描边，MDL2 字形 19px），标题 11px 次要色，单行省略；无 ToolTip |
| 紧凑模式 | 磁贴高 56，图标 chip 26，标题 12（设置里可切换） |

### 2.2 左栏

自上而下：

1. **LTools logo**（`Icon/LTools.ico`，22×22）。
2. **动作面板**（`E8A9` 网格图标，当前页 → `Tag="Selected"`：白色圆角底 + 淡投影，图标主色）。
3. **暂存区**（`E77F` 剪贴板图标；功能未上线，点击弹 toast 说明）。

入口按钮的交互态（`RailBtn` 模板）：默认透明底、次要色图标；**悬停**换成白色圆角底 + 12px / 0.16 投影、图标转主色——左栏本身是 `SurfaceAltBrush` 浅灰底，用白色而不是 `HoverBgBrush`（两者同色，会看不见）。两项都带 ToolTip（`ToolTipService.InitialShowDelay=350`、`Placement=Right`），说明是什么、能做什么；禁用态用 `ToolTipService.ShowOnDisabled` 保留提示。

### 2.3 顶栏

```
[LTools]                      [🔍 搜索动作…] [⚙] [📌] [✕]
```

- 整条顶栏可拖动窗口；按钮与搜索框不触发拖动。
- 设置入口：先关面板再打开设置「面板管理」。
- 钉住：钉住后点击外部不关闭；Esc / ✕ 仍可关。钉住状态不跨窗口保留。

### 2.4 全局区

- 区头是**靠左**的场景标签条（照 Quicker）：标签 = 场景名，选中项浅底 + 描边 + 左侧主色竖条，点击切换。
- 标签选中项记入 `Global.ActiveSceneId`，下次打开恢复（失效则用第一个）。
- 区域内容：所有分组**从上到下连续平铺**（分组名 + 磁贴网格），整区一个滚动条。左缘是分组导航条（照 Quicker）：
  一小条 = 一个分组，它只是**滚动锚点**——悬停（或点击）哪一条，视图就滚到那个分组，并且**该分组的标题贴在视图顶部**；不换页、不改内容。
- 为了让最后一个分组也能滚到顶部，内容末尾会留一块「视口高 − 最后一块高」的空白（单分组 / 搜索时不留，免得平白多一条滚动条）。
- 导航条有两种状态：**当前视口所在分组**的小条是主色、稍长稍粗，其余浅灰；手动滚动时高亮跟着走（滚到底算最后一个分组）。
- 导航条末尾「＋」新建一个空分组并滚到它；导航条刚重建后 250ms 内忽略 MouseEnter（光标被动落在新条目上，不算主动悬停）。
- 分组末尾有一个「＋」磁贴，点击弹出新建 / 选择动作菜单。

### 2.5 上下文区

- 区头同样是**靠左**的标签条：「通用」+ 所有上下文根场景（命中的窗口子场景也会补一个标签，便于看到当前选中项）。
- 标签可点击切换，只在本次会话生效（不写盘）；自动匹配结果决定初始选中项。
- 内容：选中场景的分组同样连续平铺，左缘同样是分组滚动锚点（悬停滚到那一段；末尾「＋」新建分组）；选「通用」时显示上下文「通用」分组（`Context.Common`），导航条照常可用。
- 未配置提示（照 Quicker 的底端提示条）：目标程序没有匹配到任何场景、且用户没有关掉提示时，
  区域底部显示 `尚未为“OpenChamber”添加专用设置` + 行内按钮 `添加专用设置` + 淡红 `⊘`（不再提示）。
  - 文案取进程名并去掉 `.exe`；长名省略号截断，保持单行。
  - `添加专用设置` 是文字按钮，**悬停给一层淡灰底**（提示条底色就是 `SurfaceAlt`，与默认 `HoverBgBrush` 同色，
    所以专门用 `HintActionButton` 样式把悬停换成 `BorderBrush`，否则看不出可点）。
  - `⊘` 用 `HintDismissButton`：静息淡红（`DangerSoftBrush`），悬停淡红底 + 深红（`DangerBrush`）。
  - 这句对应 Quicker 的「在未设置的软件上弹出面板时，在面板窗口底端显示创建场景提示文字」。
  - 创建场景：按目标进程生成一个上下文场景（exe + 完整路径 + 一个空分组），
    保存后关闭面板并打开设置「面板管理」，定位到该场景。
- 禁止弹出的程序（`Panel.Blocked`）：命中时面板**根本不创建**。

### 2.6 搜索与键盘

- 打开即聚焦搜索框，正常 IME 输入。
- 输入即筛选：只按**动作名称**包含匹配（忽略大小写），**不匹配内部 Id**（否则搜 `1` 会命中 `a1`）；分组内没有命中项时整个分组隐藏，「＋」磁贴也隐藏。**搜索时分组导航条隐藏、命中的分组全部平铺**，否则看不到别的分组里的命中项。
- `↑` / `↓` 在可见磁贴间移动选中；`Enter` 执行选中；`Esc` 关闭（拖动中先取消拖动）。
- **数字键不再选格**：全局钩子的 `HandleKey` 只处理 `Esc`，其余按键全部放行给窗口 / IME。
- 执行动作：先关面板，再带唤起瞬间的光标坐标执行（`windowPin.toggle` 等依赖坐标）。

### 2.7 磁贴操作

| 操作 | 行为 |
|---|---|
| 左键单击 | 执行动作；「缺失」磁贴提示动作不存在 |
| 左键按住拖动 | 快照幽灵跟随光标；源磁贴变虚线占位，光标移到哪个槽位就实时插到那里（同组重排 / 跨组移动）；松手提交，Esc 取消还原 |
| 右键（有动作） | 编辑… / 复制 / 从此组移除 / 删除动作… |
| 右键（＋） | 新建动作… / 新建组合动作… / 从动作池选择… |
| 分组名右键（设置页） | 重命名 / 删除分组 |

拖动排序的统一规格（照 Quicker 面板实测）：

| 项 | 规格 |
|---|---|
| 起拖阈值 | 位移超过 **4px** 才进入拖动；未拖动时磁贴照常触发单击 |
| 幽灵 | 圆角 8 + 向下 12px / 28px 模糊投影的主题卡片，opacity 0.96，跟随光标居中。磁贴的卡片内容由 `TileContent` 现建一份同样内容（图标 chip + 标题），不依赖栅格化快照；列表行用 `RenderTargetBitmap` 快照，取不到像素时自动改用 `VisualBrush` 重画 |
| 占位 | 源位置的虚线框：主色 55% 边框（虚线 4/3）+ 主色 10% 填充，圆角 8 |
| 实时插入 | 每次移动按「行优先」计算槽位（行内与磁贴中心比较 X），占位立刻挪过去；光标在源槽 ±10px 内不重排（防抖） |
| 让位动画 | 位置变化的磁贴做 **220ms** 让位动画，缓动近似 `cubic-bezier(0.22, 1, 0.36, 1)` |
| 结束 | 松手按占位所在分组 / 位置提交；拖动中按 Esc 取消并还原 |

以上规格由 `Views/Controls/DragFx.cs`（快照 / 占位 / FLIP）、`DragVisuals.cs`（幽灵跟随）、
`TileDragSort.cs`（磁贴）与 `ListDragSort.cs`（列表）实现，并沿用到设置里的所有排序交互：
面板磁贴、面板管理磁贴、CapsLock 快捷菜单的分组 / 菜单项、sendKeys 序列、组合动作流程步骤。

面板中的对话框入口一律「先关面板再开对话框」，不把隐藏的面板当 Owner。

### 2.8 鼠标与右键菜单（照 Quicker）

| 位置 | 左键 | 右键 |
|---|---|---|
| 面板空白 / 区背景 / 标题栏 / 左栏 | 空白处按住移动 >4px 拖动窗口；中键点空白关闭面板 | 区菜单：新建动作 / 新建组合动作 / 从动作池选择 / 新建分组 / 在设置中管理；标题栏与左栏是面板菜单：钉住 / 面板设置 / 关闭 |
| 分组标题 / 左缘分组导航条 | 标题双击就地改名（Enter 保存、Esc 取消、失焦保存） | 分组菜单：在此组新建动作 / 新建组合动作 / 从动作池选择 / 重命名分组 / 删除分组 / 在设置中管理 |
| 磁贴 | 执行；按住拖动排序 | 编辑 / 复制 / 从此组移除 / 删除动作 |
| 场景标签（全局 / 上下文 / 通用） | 切换场景 | 编辑场景 / 新建同类场景 / 改为显示通用 / 删除场景 |
| 设置 · 场景行 | 选中 | 重命名场景 / 新建动作 / 新建分组 / 新建窗口子场景 / 删除场景 |
| 设置 · 分组卡片 | 点名字编辑（悬停显边）、铅笔改名 | 重命名分组 / 新建动作 / 新建组合动作 / 从动作池选择 / 删除分组 |
| 设置 · 列表 / 详情空白 | — | 新建场景 / 新建分组 / 在此场景新建动作 |

实现：磁贴、场景标签、分组导航条各自挂 `ContextMenu`；其余空白由窗口的
`ContextMenuOpening` 兜底（`FindContextMenuOwner` 保证不抢控件自己的菜单，
`IsInteractive` 让输入框 / 滚动条 / 分割条保持原生行为）。空白拖动只在
`PreviewMouseLeftButtonDown` 记住起点，`PreviewMouseMove` 超过 4px 才 `DragMove()`。

## 3. 数据模型

动作本体仍在 `AppConfig.Actions`（`ActionDto`），面板只存 **actionId 引用**。

```jsonc
"Panel": {
  "Preferences": {
    "Width": 560,
    "Height": 620,
    "ShowGroupTitles": true,     // 视图选项：显示分组名
    "CompactTiles": false,       // 视图选项：紧凑磁贴
    "GlobalRatio": 0.5           // 全局区占上下两区总高的比例（分割条拖动后记住）
  },
  "Global": {
    "Scenes": [
      {
        "Id": "s1",
        "Name": "默认",
        "Icon": "app",
        "Enabled": true,
        "ParentId": null,
        "Match": { "Path": null, "Exe": null, "TitleContains": null, "ClassName": null },
        "Groups": [
          { "Id": "g1", "Name": "未分组", "Actions": ["a1", "a3"] }
        ]
      }
    ],
    "ActiveSceneId": "s1"
  },
  "Context": {
    "Scenes": [
      {
        "Id": "s2",
        "Name": "微信",
        "Icon": "app",
        "Enabled": true,
        "ParentId": null,
        "Match": { "Path": null, "Exe": "WeChat.exe", "TitleContains": null, "ClassName": null },
        "Groups": [ { "Id": "g2", "Name": "常用", "Actions": [] } ]
      }
    ],
    "Common": [ { "Id": "g3", "Name": "常用", "Actions": [] } ]
  },
  "Blocked": [ "game.exe" ],
  "HintDismissed": false
}
```

规则：

- `Global.Scenes` / `Context.Scenes` 是扁平列表；上下文子场景通过 `ParentId` 指向父场景。
- 全局场景不使用匹配条件（字段保留但不参与匹配）。
- `Context.Common` 是未匹配时的兜底分组；始终至少保留一个分组，否则用户没有地方放动作。
- `Blocked` 与 `HintDismissed` 独立存储：不建场景也能禁止弹出 / 关掉提示。
- `AppConfig.Panel` 为可空：`null` 表示「还没迁移过」，触发旧 `SuperPanel.Pages` 迁移；
  一旦迁移落盘（或用户手动清空后保存），不再重复迁移。
- 旧 `SuperPanel.Pages` / `LastPage` 保留在模型里只为迁移读取，新代码不再写入。

## 4. 上下文匹配

### 4.1 目标窗口信息

唤起瞬间抓取（必须在创建面板窗口**之前**，否则前台会变成 LTools 自己）：

- `HWND`
- 进程完整路径、进程名
- 窗口标题
- 窗口类名

**句柄取哪个窗口**（照 Quicker）：

- **长按右键唤起** → **按下那一刻光标下的顶层窗口**（`WindowFromPoint` + `GetAncestor(GA_ROOT)`）。
  右键不会自动激活后台窗口，所以 `GetForegroundWindow` 可能还停在别的程序上：
  例如全屏的播放器在后面、资源管理器在前面（前台），在播放器露出的区域长按右键，
  Quicker 会**先把播放器激活**，上下文也取播放器而不是资源管理器。
  LTools 同样先 `ActivateNoWait` 目标窗口（面板关掉后焦点回到它、后续动作也作用在它身上），
  再按句柄解析场景；面板随后用 `ActivateNoWait(面板句柄)` 兜底抢回前台。
- **键盘唤起**（CapsLock+T）→ 当前前台窗口（光标可能停在无关窗口上，不能按光标算），也不额外激活。
- 光标下正好是 LTools 自己的**不可激活浮层**（提示卡片 / 录制指示器这类
  `WS_EX_NOACTIVATE` / `WS_EX_TOOLWINDOW` 窗口）时，忽略它、退回前台窗口。
- 桌面 / 任务栏这类 shell 窗口（`Progman` / `WorkerW` / `Shell_TrayWnd` …）只当上下文匹配对象，不激活。

UWP / 托管进程取不到真实 exe 时（如 `ApplicationFrameHost.exe`）退化为窗口条件匹配；
细节记录到运行日志，不阻塞面板。

### 4.2 优先级

1. **完整路径完全相同**（忽略大小写）的程序场景。
2. **进程名相同**（`WeChat.exe`）的程序场景。
3. 父场景命中后，再匹配它的**窗口子场景**：
   - 标题包含（忽略大小写） / 类名精确。
   - 恰好一个命中 → 用该子场景。
   - 多个命中 → 回退父场景并 `AppLog.Warn`（Quicker 文案「同时匹配多个窗口条件子场景，已回退父场景」）。
4. 没有程序场景命中时，匹配只带窗口条件的根场景。
5. 都没有 → 使用 `Context.Common`，并显示未配置提示。

同级多个命中取列表第一个，并 `AppLog.Warn`（对应 Quicker「同时匹配多个程序场景」）。

### 4.3 禁止弹出

`Context.Blocked` 命中目标窗口的进程名（或完整路径）时，`SuperPanel.Show()` 直接返回，
不创建窗口、不改变光标记忆。日志记一条 info。

## 5. 设置页

### 5.1 面板管理（导航 `superpanel`）

左栏「面板管理」是**带下拉的主导航**：点它先显示主页面（常规），同时在它下面展开三个二级项
（常规 / 场景 / 禁止弹出），选中的二级项与父项一起高亮，父项箭头朝下；离开面板管理时下拉收起、箭头朝右。
`LastNavPage` 记录的是二级项的 `Tag`（`superpanel-general` / `superpanel-scenes` / `superpanel-blocked`），
父项 `superpanel` 作为「回常规」的入口保留。三个页面由 `PanelManageView.ShowPage(page)` 切换。

**常规**

- 启用超级面板（与「通用」页同一开关，双向同步）。
- 长按阈值 100–800ms（沿用 `AppState.SuperPanelThresholdMs`）。
- 视图选项：显示分组标题 / 紧凑磁贴。
- 「重新显示未配置提示」：清 `HintDismissed`。

**禁止弹出**

- 禁止弹出的程序：输入进程名 / 完整路径添加，列表内 ✕ 移除。
- 命中列表时面板**根本不创建**（见 §4.3）。

**场景**

左侧场景列表（分组标题 + 整行按钮，窗口子场景缩进）：

```
全局场景
  默认
  示例场景
上下文场景
  通用（未匹配时显示）
  微信
    聊天窗口（窗口子场景）
```

- 新建菜单：全局场景 / 上下文程序场景 / 窗口子场景（后者挂在选中场景下）。
- 删除：删除场景（父场景同时删子场景）；删除前确认。
- 选中「通用」时，右侧只显示 `Context.Common` 的分组。
- 切换场景时匹配条件回到折叠态（新建成上下文场景 / 子场景时直接展开，方便填条件）。

右侧详情：

- 场景标题（可直接改名）+ 类型标签 + 「启用」勾选。
- **匹配条件默认折叠成一行摘要**（方案 3）：绿点 = 有可用条件，灰点 / 红字 = 无条件；
  摘要例 `进程 WeChat.exe · 路径 C:\…\WeChat.exe`。点整条展开表单：进程名、完整路径、
  窗口标题包含、窗口类名 + 实时「匹配预览」+「重置 / 应用匹配条件 / 收起」。
- 匹配预览按 resolver 语义解释：完整路径 > 进程名 > 窗口条件；根场景的标题 / 类名不参与匹配，
  只在窗口子场景里生效。
- **动作管理常驻**（规则折叠后仍占满详情）：分组标题 + 重命名 / 删除 + 磁贴网格 + 「＋」，
  顶部「＋ 添加分组」。分组名可直接点开编辑，旁边有铅笔按钮、卡片右键也有「重命名分组」；
  Enter 保存、Esc 还原、失焦保存。磁贴点击 = 编辑该动作；右键 = 从分组移除 / 删除动作（确认框列出全部引用位置）；
  磁贴支持拖动排序（与面板同一套 `TileDragSort`）。

## 6. 旧数据迁移

触发条件：`AppConfig.Panel == null`。

1. 新建全局场景「默认」。
2. 遍历 `SuperPanel.Pages`：
   - 只有一页：该页非空动作放入分组「未分组」。
   - 多页：每页一个分组「第 N 页」；空页跳过。
   - 每组内去掉 null / 空串 / 重复 Id，保留原顺序。
3. 若没有任何非空页：建一个空分组「未分组」。
4. `Global.ActiveSceneId` 指向「默认」。
5. `Context.Common` 建一个空分组「常用」。
6. 经 `ConfigIO.Modify` 落盘；读取失败（`LoadStrict` 抛错）则只保留内存态，**不覆盖**用户配置。

迁移后 `SuperPanel.Pages` 原样保留（不再使用），便于回退旧版本。

## 8. 阶段计划

1. **数据层**：DTO、`PanelLibrary`、前台抓取、匹配器、旧页迁移。
2. **面板窗口**：新布局、磁贴、搜索、双区、提示条、拖动重排、尺寸记忆。
3. **控制器**：阻止弹出、只留 Esc、删除引用改走面板库。
4. **设置**：面板管理页、动作表格 + 引用列、导航改名。
5. **收尾**：示例配置、文档、构建 0 错 0 警；实机验证以下场景：
   - 旧配置迁移后两个区都能显示；
   - 未配置程序显示提示并能一键建场景；
   - 钉住后点外部不关；搜索框 IME 正常；
   - 禁用程序不弹面板；
   - 删除动作时引用位置列在确认框里。

## 9. Quicker 2.0 证据（逆向记录）

从 Quicker 2.0 安装目录的面板 WebView 资源提取（`BEWDE6ma.js` + `BaPFzblP.css`）：

- 主面板最小 320×420；标题栏 36px。
- 搜索框 280×24，圆角 12。
- 区域头 28px；两个区域各 50%，最小 90px；中间分隔条 8px。
- 磁贴最小宽 72；图标 36；标题 11；紧凑模式磁贴高 34、左栏 38 DIP（标准 50 DIP）。
- 官方文案：
  - 「同时匹配多个窗口条件子场景，已回退父场景」
  - 「同时匹配多个程序场景」
  - 「目标窗口没有可用于程序场景匹配的逻辑进程」
  - 「在未设置的软件上弹出面板时，在面板窗口底端显示创建场景提示文字」
- 管理入口：设置 → 动作 → 全部动作；场景、动作与触发管理（左场景树 + 右动作 + 触发页签）；
  右键「管理引用位置…」。
