## 0. 前言

本项目受 [Capslock+](https://capslox.com/capslock-plus/) 启发，并借鉴了 vim 的很多键位。主要自用于 Win11 24H2，其他系统未测试。

v2.0.0 起由原 AutoHotkey v2 脚本重构为 **C# / .NET 8 / WPF** 桌面程序，功能行为与 AHK 版本一致，性能与可维护性更好。重构细节见 [docs/WPF_MIGRATION_PLAN.md](docs/WPF_MIGRATION_PLAN.md)。

## 1. 构建与运行

### 依赖

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)（Windows）
- Windows 10/11（托盘、全局钩子、WPF）

### 构建

```bash
# 开发构建（无清单，调试）
dotnet build

# 发布构建（带 requireAdministrator 清单，双击即提权）
dotnet build -c Release
# 或发布单文件
dotnet publish -c Release -r win-x64 --self-contained false
```

输出位于 `bin/Debug/net10.0-windows10.0.19041.0/LTools.exe`（或 `Release`）。双击即提权运行（`app.manifest` 已配置 `requireAdministrator`）。

> 全局键盘/鼠标钩子需管理员权限，故发布版带提权清单。开发调试时可用 `-p:NoWin32Manifest=true` 免提权快速启动。

## 2. 基本功能

### 2.1 CapsLock 重映射

- **CapsLock 单击（≤0.3s）**：发送 Esc 键
- **CapsLock 按住**：当作修饰键，配合其它键触发「设置 → 快捷键」里配好的动作（默认那批见 §4）
- 按住后按了别的键，这次就不再算单击（不会先发一个 Esc 再执行动作）

### 2.2 CapsLock 状态管理

- 自动维持 CapsLock 关闭状态
- **Ctrl+CapsLock**：手动切换 CapsLock 状态

### 2.3 启用 / 停用

设置里三个互相独立的开关（都即时落盘，重启保持；托盘菜单里有对应的「启用 CapsLock 修饰键 / 启用超级面板」两项）：

- 「通用」页 **CapsLock 可作为快捷键修饰键**：开启时 CapsLock 被接管——轻按发 Esc、按住配合其它键触发快捷键、灯保持关闭（`Ctrl+CapsLock` 手动开 / 关大写锁定）。关掉后 CapsLock 恢复原生大小写切换，带 CapsLock 前缀的绑定随之不触发
- 「通用」页 **屏幕边缘滚轮调音量**：鼠标停在屏幕边缘时滚轮调系统音量，边可选底部 / 顶部 / 上下（见 §5.2）
- 「面板管理 → 常规 → 行为」**启用超级面板**：关掉后长按右键不再弹面板；同一个卡片里的长按阈值也随之置灰

### 2.4 托盘与日志

- 托盘右键：速记 / 动作面板 / 设置 / 开始·停止录制宏 / 键鼠宏… / CapsLock 修饰键与超级面板开关 / 关闭所有悬浮项 / 退出
- 动作跑完按设置「通用 → 运行提示」决定是否弹提示；**失败一定弹**，并且是常驻卡片（标题带失败位置，点一下打开日志目录）

## 3. 实用小功能

### 3.1 放大镜

- **CapsLock+Tab**：开关放大镜
- **Ctrl+Alt+滚轮**：放大缩小

### 3.2 快速搜索

- **CapsLock+Q**：搜索选中的文本内容
  - 网址 → 直接打开
  - 磁盘绝对路径 → 打开该路径
  - 普通文本 → Bing 搜索
  - 无选中 → 不执行

## 4. 文本编辑增强（预设快捷键）

下面这些键位预置在「快捷键 → CapsLock 经典」组里，绑的是**常用功能**里的「光标移动 / 文本选择 / 删除与撤销」条目（见 §6）：想放到面板、悬浮或换成别的键，直接拖 / 添加那条功能即可，不必先建动作。

> 旧版的「CapsLock+数字」快捷菜单已经下线，跟着一起走的是：词跳 `A/G`、词选 `H/;`、选到行首 / 行尾 `U/O`、删到行首 / 行尾 `M/?`、文件首尾变体、`< >`、独立剪贴板 `X/C/V`、任务视图 `B`、`Enter` / 右 Shift 插行、括号输入 `' [ ] - =`、符号定位 `P`、帮助面板 `` ` ``、`CapsLock+Esc` 禁用开关、`Ctrl+Alt+I` 调试信息。想要哪个，自己在动作编辑器里拼回来再绑快捷键即可。

### 4.1 光标移动

- **CapsLock+W**：移到行首　**CapsLock+R**：移到行尾
- **CapsLock+E**：上移一行　**CapsLock+D**：下移一行
- **CapsLock+S**：左移一字符　**CapsLock+F**：右移一字符

### 4.2 文本选择

- **CapsLock+I**：选中上一行　**CapsLock+K**：选中下一行
- **CapsLock+J**：选中左一字符　**CapsLock+L**：选中右一字符

### 4.3 删除与撤销

- **CapsLock+,**：退格　**CapsLock+.**：删除
- **CapsLock+Backspace**：删除整行（行首 → 选中到行尾 → 删除）
- **CapsLock+Z**：撤销　**CapsLock+Y**：重做

## 5. 窗口与音量

### 5.1 窗口置顶

- 内置功能「窗口置顶」：把**鼠标位置所在的窗口**切换置顶 / 取消置顶
- 它不是写死的鼠标手势，绑快捷键（如 `CapsLock+P`）、放进面板磁贴或悬浮按钮都行

### 5.2 音量调节

- **屏幕边缘滚轮**：鼠标停在屏幕边缘 8px 内滚动滚轮 → 调节系统音量（向上增大、向下减小，每次 ±1 档），无需按 CapsLock
- 算哪条边在设置 →「通用」→「屏幕边缘滚轮调音量」里选：**屏幕底部 / 屏幕顶部 / 上下都算**；关掉该开关就完全放行滚轮
- 多显示器只认光标所在的那块屏

## 6. 常用功能 / LTools 功能

除了「动作」，还有两类**内置功能**：**常用功能**（作用于系统与编辑：截图、音量、剪贴板历史、放大镜、光标移动 / 文本选择 / 删除与撤销…）与 **LTools 功能**（作用于 LTools 自身：打开面板 / 速记 / 设置、录制宏、退出…）。它们不是步骤单元，不会出现在动作编辑器左栏，但可以像动作一样：

- 放进**超级面板**：右键空白处 / 分组 →「常用功能 ▸」或「LTools 功能 ▸」，点一下就加一颗磁贴；
- 绑**快捷键**：快捷键页「添加快捷键…」的选择器里直接能选到（默认的 CapsLock 经典组绑的就是其中 20 条）；
- **悬浮**到桌面：磁贴右键「悬浮此功能」；
- 有参数的功能（如「截图」的范围、「音量 +」的格数）在加入时会先弹参数表，之后磁贴右键「参数…」可改。

内置功能只读（不能编辑 / 导出 / 删除），不想要就从面板或快捷键里移除。**CapsLock+空格** 故意留空（旧的鼠标模式已移除）。

## 7. 速记功能

### 7.1 基本操作

- **CapsLock+N**：打开速记窗口
  - 快速记录笔记、想法或任何文本内容
  - 保存时自动添加时间戳记录创建时间
  - 保存后不关闭窗口，自动加载保存的文件内容进入编辑模式
  - 动作里也能读写速记：「写速记」动作 +「读速记」取值器，详见 §10.9

### 7.2 查看已记速记

- 左列列表显示速记文件（标题、修改时间），支持搜索过滤（标题优先匹配，不命中才扫正文，300ms 防抖）
- **单击**列表项即载入内容到右列编辑区
- **右键**列表项（或 **Ctrl+Del**）删除选中的速记，需确认；删除的是列表条目本身，只有恰好是当前编辑中的那条才会清空编辑区

### 7.3 保存

- 默认保存：有标题（首行）以标题为文件名；无标题以时间戳为文件名
- 保存位置：程序目录下的 `速记/` 文件夹，按分类子目录组织
- **Ctrl+S**：保存当前速记

## 8. 快捷键

### 8.1 预设组

- 设置 →「快捷键」：左边是**预设组**，右边是组内的「快捷键 → 动作」表
- 可以同时启用多个组；组和条目都能单独启停，也能上下调整顺序（排在前面的优先）
- 首次启动播种一组「CapsLock 经典」（20 条，见 §4）；删掉的条目不会再被塞回来（播种版本记在 `configs/hotkeys.json`）
- 旧版的「CapsLock+数字」菜单组不再自动导入；想保留哪条，自己新建绑定即可
- 一条绑定只存「快捷键 + 动作 Id」：动作本体在动作管理里编辑，删动作时引用它的绑定一起清掉

### 8.2 添加 / 编辑

- 「添加快捷键…」里**直接按下组合键**录制（Esc 取消），再从动作池选一个动作或内置功能（常用功能 / LTools 功能）
- 组合键可以带 Ctrl / Shift / Alt / Win，也可以带 CapsLock——走低级键盘钩子匹配（`RegisterHotKey` 不支持 CapsLock 修饰键）；修饰键**精确匹配**，`CapsLock+S` 不会在 `CapsLock+Ctrl+S` 时触发
- 单键（无修饰键）只允许 F1–F24 / Insert / Home / End / PageUp / PageDown / Pause / PrintScreen / ScrollLock，避免抢日常输入
- 同一个组合键出现多次时表里标红：只有排在前面的那条会触发

### 8.3 生效范围（白 / 黑名单）

- 全局默认：所有窗口 / 只在白名单 / 排除黑名单；名单可写进程名（`chrome.exe`、`chrome*`、完整路径）、窗口标题（包含匹配，支持 `*` `?`）、窗口类名
- 每条绑定都能单独覆盖：跟随全局默认 / 所有窗口 / 白名单 / 黑名单
- 前台程序由 `SetWinEventHook` 跟踪、进程名在后台线程解析，钩子回调里只做字符串比较；**取不到前台程序时照常触发**
- LTools 自己的窗口（设置 / 面板 / 速记 …）上不触发快捷键

### 8.4 动作面板（原超级面板）

- **CapsLock+T**、鼠标长按右键或托盘「动作面板」唤起（以光标为中心弹出）；打开即聚焦搜索框，输入即按**动作名称**筛选，`↑` / `↓` 选择、`Enter` 执行、`Esc` 关闭
- **上下双区**：
  - **全局区**：与前台窗口无关，可有多套全局场景；区头靠左的标签点击切换
  - **上下文区**：长按右键先把**鼠标下的那个窗口激活**（照 Quicker，面板关掉后焦点留在它身上），再按它的程序（完整路径 → 进程名）和窗口条件（标题包含 / 类名）自动选场景；键盘唤起（CapsLock+T）仍按前台窗口。区头标签（通用 / 各程序场景）也可点击切换；没配置时底部显示 Quicker 风格的提示条「尚未为“X”添加专用设置」，右侧「添加专用设置」按钮（悬停淡灰底）可直接为它建场景，末尾淡红 ⊘ 关闭提示
  - 两区中间的分割条可拖动调高度，比例在关闭时记住（`GlobalRatio`）
  - 每区**连续平铺所有分组**，区域左缘是一列小横条，一小条 = 一个分组，它只是**滚动锚点**：**鼠标悬停就把那个分组的标题滚到视图顶部**（不换页，最后一个分组靠末尾留白也能贴顶），滚动时高亮跟着视口走；末尾「＋」新建分组。搜索时这列导航让位
- 磁贴照 Quicker：透明底、无卡片边框、只有 4×2 间距，悬停才出现软底；图标是 36px 的淡底 chip，标题 11px 次要色
- 磁贴按可用宽度均分（最小 72），点击执行；按住拖动时源磁贴变虚线占位、快照幽灵跟随光标，移到哪个槽位就实时插到那里（组内重排 / 跨组移动），Esc 取消；右键编辑 / 复制 / 从此组移除 / 删除动作
- 同一套拖动排序交互也用于面板管理里的场景 / 分组与动作编辑器的步骤列表
- 「＋」磁贴新建动作或从动作池选择；场景、分组与匹配条件的完整管理在设置「面板管理」
- 钉住后点外部不关闭，方便连着点几个动作；钉住期间上下文不跟随前台变化
- 照 Quicker：**空白处左键按住就能拖动面板**（不只顶栏），中键点空白关闭面板；右键菜单铺开到各处——空白 / 分组出「新建动作 / 从动作池选择 / 新建分组 / 重命名 / 删除分组 / 在设置中管理」，场景标签出「编辑场景 / 新建场景 / 删除场景」，标题栏与左栏空白出「钉住 / 面板设置 / 关闭」；分组标题双击可**就地改名**（Enter 保存、Esc 取消）
- **用完即收**：执行动作、打开设置、新建 / 编辑 / 复制 / 删除动作、从动作池选动作，操作完成（取消也一样）都会收起面板。留在面板上的只有钉住和拖动重排
- 收起是**直接关闭**而不是「藏起来」：新建 / 编辑等入口先关面板再开编辑器，既不会出现「编辑器与面板并排」，也没有收起瞬间的黑窗闪烁；编辑器开着时仍可长按右键唤起面板
- 设置「面板管理」可把某个程序加入「禁止弹出」：在它上面长按右键不会弹面板

### 8.5 悬浮动作 / 悬浮分组

- **悬浮此动作**：面板磁贴右键 → 悬浮此动作，动作就变成一个**正方形置顶按钮**待在桌面上（上面图标、下面动作名），单击直接运行（不用先唤面板）
- **悬浮此分组**：面板分组右键 → 悬浮此分组，整组动作排成一排（右键「方向」可改为竖向一列）；也可以把两个悬浮按钮**拖近**（间距 ≤ 12 像素）自动成组
- 悬浮窗**不抢焦点**：点按钮时焦点还留在你正在用的程序上，动作的键鼠注入不会打到自己
- 新悬浮按钮**出现在鼠标指针处**（按钮左上角在指针左上约 40 像素，照 Quicker 的做法）；同一位置已有按钮就自动错开
- 点「悬浮此动作」后**面板不会关**，可以接着悬浮别的动作
- 悬浮按钮**永远显示在超级面板前面**（照 Quicker）：面板显示或激活后会自动把悬浮按钮重新顶回最前面
- 悬浮项**全局常驻**：不按前台进程显隐，一直在桌面上
- **无状态**：悬浮按钮只在本次运行里存在，关掉 LTools 就没了（与 Quicker 一致），下次要用再从面板悬浮；偏好设置照旧记住
- 鼠标：单击运行 · 按住拖动（松手吸附屏幕边缘，靠近另一个悬浮按钮就合并成组）· 中键关闭 · 右键菜单
- 右键菜单：运行 / 编辑动作 · 锁定位置 · 按钮大小（36/44/52/64）· 不透明度（100/80/60%）· 方向（分组）· 拆分为独立悬浮（该动作 / 全部）· 关闭
- 设置「面板管理 → 常规 → 悬浮动作」：中键关闭、悬停提示完整名称、拖动吸附边缘，以及「关闭全部悬浮项」（托盘也有）
- 一个动作同时只有一个悬浮按钮；删除动作后按钮自动消失。防呆上限 32 项
- 完整规格与限制见 `docs/FLOATING.md`

## 9. 键鼠宏录制 / 回放

把一段真实的键鼠操作录下来，之后一键原样重放。

**一个键鼠宏就是一个动作**：录制结束时 LTools 自动建一个「1 步 · 回放宏」的动作，并放进面板当前全局场景的第一个分组——面板上点一下就是回放，也可以绑快捷键或悬浮到桌面。宏本身没有第二套界面：管理入口统一在「设置 → 键鼠宏」。

### 9.1 录制

- **开始录制**有四个入口，效果完全一样：按录制热键（默认 `Ctrl+F2`，**全局**）、托盘菜单「● 开始录制宏」、面板「＋」或分组菜单里的「● 录制键鼠宏…」、设置 →「键鼠宏」→「● 录制新宏」
- 录制中再按一次录制热键即停止；托盘菜单标题此时变成「■ 停止录制宏（Ctrl+F2）」，指示器上也有提示。从设置页 / 编辑器 / 面板发起的录制，那个窗口会先藏起来（免得把自己录进去），停止后自动显示回来
- **录制中热键一定能停**：开始录制时把该热键临时注册到系统，结束立刻注销——即使低级钩子被系统摘掉、修饰键判定异常，按录制热键也能停下
- 停止后**自动保存、自动挂成动作**，不弹命名框，自动命名「录制 MM-dd HH:mm:ss」；动作名、宏名是同一个，在「键鼠宏」页里改一次两边都变
- 「重新录制」沿用同一个宏与动作（事件文件整体替换），所以面板 / 快捷键上的引用不用重建
- 热键录入是**录制式**的：在设置 →「键鼠宏」里点热键框后直接按下组合键即可（Esc 取消，Tab 结束），**录到有效组合立即生效并写盘**；输入框显示 `Ctrl+F2`，配置文件统一存小写 `ctrl+f2`
- 热键**不强制要求修饰键**：可以直接用 `F2`、`F8`、`Pause`、`PrintScreen`、`Insert`、`Home`、`End`、`PageUp/PageDown` 等不产生字符的键。字母 / 数字 / 空格 / 方向键等会干扰日常输入，单独使用会被拒绝并提示搭配 `Ctrl / Shift / Alt / Win`；无修饰键热键只在「完全没按修饰键」时触发，`Ctrl+F2` 不会误触发裸 `F2`
- 刚开录 600ms 内的「停止」会被忽略：录制按钮被双击 / 鼠标抖动时不会出现「一点录制就说已停止」
- 录制期间窗口顶部显示录制指示器（事件数 + 停止热键提示）
- 录制期间 LTools 进入**透明模式**：CapsLock 修饰键、快捷键、超级面板、边缘滚轮音量等全部暂停，录到的输入就是目标应用实际收到的输入；CapsLock 本身不录入也不生效

### 9.2 回放

- 回放入口：面板磁贴（右键「▶ 试放宏」可先预览）、快捷键、悬浮按钮，或任何动作里的「回放宏」步骤
- 回放期间右下角挂一条常驻提示（宏名 + 停止热键），结束自动收起
- **停止**：按停止回放热键（默认 `Ctrl+F3`）。它只在回放期间临时注册、结束立即释放；若该组合键已被其他程序占用，注册失败也不影响回放——键盘钩子会先一步吞掉该组合键并停止宏（同时提示一次）
- **回放参数按宏独立**：在「设置 → 键鼠宏」里点某个宏的「回放设置…」，可以只改这一个宏的倒计时 / 速度倍率 / 循环次数（含无限循环）；**留空 = 跟随默认**，用该页「回放默认值」里的全局值。列表行会把单独设过的参数直接标出来（如 `2× · 无限循环`）
- 回放按录制时的真实时序注入键盘与鼠标事件；结束时强制释放所有按键与鼠标键，不会卡键；每轮按录制时长补足末尾静默后再开始下一轮
- 鼠标移动用 `SendInput` 绝对坐标注入（虚拟桌面），换了分辨率或显示器布局会按比例缩放
- 鼠标移动按「采样间隔 / 采样位移」抽稀，避免事件文件过大（全局录制参数，在「键鼠宏 → 高级」里调）

### 9.3 宏文件

- 宏的事件本体存数据根 `macros/<id>.json`，元数据（名称、时长、事件数、回放参数）存 `configs/macros.json` 的 `Macros.Items`，动作里只存宏 Id；备份会一起打包
- 「回放宏」也可以作为**任何动作里的一个步骤**（工具箱「键鼠交互 → 回放宏」，参数是宏下拉）——单独把动作拷到没有该宏的机器上会失效，步骤行会标出「宏文件缺失」
- **按引用回收**：不被任何动作步骤引用的 `macros/*.json` 与元数据会在启动时清掉；删除一个宏动作 = 删掉它的宏文件
- 删除宏（「键鼠宏」页的「删除」，或删掉它的动作）会连带删掉引用它的动作，并清掉面板 / 快捷键 / 悬浮里的引用

## 10. 自动化流程（动作）

一个动作就是一串「功能单元」步骤：可以插条件分支、循环和变量，配合屏幕图像识别 / 取色 / 鼠标操作做轻量自动化，也能把常用的一段步骤收进「子动作」反复调用。入口：设置 →「动作管理」新建 / 编辑动作，或从动作面板当场新建。

### 10.1 编辑器与流程控制

- 编辑器分三栏：左「工具箱」、中「步骤」、右「变量 + 动作属性」。工具箱完全由单元注册表生成（按分类浏览，分类可折叠 + 搜索），点一下就把该单元插到选中步骤之后（弹参数表单）；**新增功能单元不需要改编辑器代码**。
- **从工具箱拖进步骤**：按住单元拖到列表里，出现在行间就是插到那里（含空分支、末尾），松手按**默认参数直接插入**（必填项没有默认值时才弹表单）；拖到列表上下边缘会自动滚动。`Ctrl+点击` 单元 = 不拖也按默认参数直接插；单元右键还有「添加…（填参数）/ 直接添加 / 添加到末尾」。
- **步骤右键菜单**：编辑 / 复制一份 / 复制 / 粘贴到下方 / 在上方或下方插入单元（按分类的子菜单）/ 只运行这一步 / 从此行试运行 / 跳过这一步 / 上移下移 / 删除；多选时给「运行选中的 N 步」；标记行给「插入单元到此处 / 粘贴到此处」，列表空白处给「在末尾插入单元 / 粘贴到末尾」。
- **多选与撤销**：`Ctrl` / `Shift` 点选多行，右键菜单变成「复制 / 复制一份 / 跳过 / 删除选中的 N 步」；`Ctrl+Z` 撤销、`Ctrl+Y` 重做（标题旁有 ↶ / ↷ 按钮，最多 50 步，只回退步骤树、不动变量表）。快捷键：`Enter` 编辑、`Delete` 删除、`Space` 跳过 / 启用、`Ctrl+C / Ctrl+V` 复制粘贴、`Ctrl+D` 复制一份、`Alt+↑ / Alt+↓` 上下移。
- 步骤行显示图标 + 名称 + 一行摘要 + 输出变量；缩进表示嵌套，`否则 / 结束如果 / 结束循环` 是标记行，空分支有一行灰色占位行，选中后从左侧添加即可放进该分支。**单击选中一眼可见**：行卡片变灰底、加主色描边和左侧 3px 竖条（多选时每一行都有）。
- **折叠块**：带子步骤的「如果 / 循环」行前面有 ▾ / ▸，点一下收起整块（子步骤不占行、步号照旧连续，摘要里显示「已折叠 N 步」）；右键「折叠 / 展开子步骤」，列表空白处右键可「全部展开 / 折叠所有块」。折叠只是编辑器的显示状态，**不写进动作 JSON**。
- **步骤搜索**：中栏顶部「搜索步骤…」按名称 / 摘要 / 单元键 / 参数文本定位（多个关键词用空格分开），`Enter` 下一处、`Shift+Enter` 上一处、`Esc` 清空；命中在折叠块里会**自动展开**再选中，右侧显示「2/7」。
- **变量引用与改名同步**：变量行下面写「来源 · 引用 N 处」（写入 = 步骤的输出映射，读取 = `${名}` / 变量取值 / 内联取值），悬停看「N 处写入 · M 处读取」；**改变量名会把步骤里的 `${旧名}`（含 `旧名.成员`）、变量取值、输出映射一起改掉**，步骤摘要跟着新名字变。仍被引用的变量不让删（先改步骤）。
- **拖动排序**：拖起来出现幽灵 + 插入线，松手才落数据；可落在任意步骤的上 / 下方（换一条分支就是移入该分支），也可落在空分支占位行上。标记行不是落点，**不能把一步拖进它自己的分支**。也可以用 `↑` / `↓`（`Alt+↑` / `Alt+↓`）。**多选拖动**：按住已选中的行（不带 Ctrl / Shift）就把整组一起拖走——幽灵写明「N 步 · 第一步的名字」，按显示顺序落位、跨分支保持相对顺序；选中的块和块里的子步骤一起选时只移动块本身（子步骤跟着走，不会重复插入），拖回原位不算改动、不记撤销。
- 双击步骤（或选中后点「编辑」）打开参数对话框：表单按单元定义生成——文本 / 多行 / 代码（等宽多行 + 「检查语法」）/ 数字 / 开关 / 枚举 / 文件 / 文件夹 / 图片 / 变量 / 条件；**每个输入框下面有一行说明**，写清该填什么（单位、格式、可填哪些值、能不能用 `${变量}`），下拉与开关不再重复「请选择」这类废话；条件参数随其它参数实时收起 / 展开；底部按输出定义勾选映射到变量。
- **参数对话框的连续编辑**：底部「‹ 上一步 / 下一步 ›」会**先保存当前步骤**（必填项照常校验）再打开相邻步骤，`Alt+←` / `Alt+→` 同样；添加新步骤时多一个「保存并继续添加」——保存后原地再开一个同单元的空表单，适合连着加一串。**常用 / 高级参数**：超时、轮询间隔、相似度、焦点延时这类调优项收进「高级参数（N）」，默认折叠，**已经设过非默认值的会自动展开**（不会把用户填过的参数藏起来）。
- 每个参数三态：**文本模板**（原「字面量」：直接写内容，可含 `${变量}`）/ **变量** / **取值单元**（运行时现场取一个值，如读剪贴板、识别文字、找图）。选了取值单元后，值下面有一行说明：还缺哪些必填参数、该点「填参数…」还是「改参数…」；参数用同一个表单继续编辑，可递归嵌套。
- **固定区域不用手抄坐标**：「区域」选「固定区域」后，点旁边的「框选…」在屏幕上拖一块，自动填好 `x,y,w,h`（截图、截图找图、截图找文字、文字点击、图片点击都是这样）。「区域」行本身也有一个「框选…」，不用先切到固定区域；框选模板图时还会顺手把搜索区域收紧到刚框的那块。
- 下拉里的选项（「操作」「区域」「识别引擎」等）显示中文名——去掉首尾空白 / 读取剪贴板 / 前台窗口 / PP-OCRv6 快速；配置里存的仍是英文键（`trim` / `read` / `foreground` / `v6tiny`），旧配置照旧能读。步骤行摘要也一起翻译。
- 「流程」分类提供：设置变量（覆盖 / 追加）、如果（否则）、重复（固定次数）、遍历列表、条件循环、跳出循环、进入下一次循环、停止、调用子动作。循环的下标 / 当前项通过步骤的「输出」映射到变量。
- 工具箱的分类按「动手 → 判断 → 加工 → 取材」排：**键鼠与输入 / 流程 / 文本与数据 / 剪贴板 / 文件 / 窗口与程序 / 屏幕 / 界面 / 脚本**（顺序只在 `Core/Actions/UnitCategories` 里定，左栏与「内联取值」下拉共用）。剪贴板相关的 5 个单元（读写文本、历史、清空、文件、图片）统一在「剪贴板」下；「发送文本」「读取选中文本」归「键鼠与输入」；「文本处理」「正则提取」与计算 / JSON / 列表 / 时间 / 速记 / 上一步的错误同属「文本与数据」；「程序」「窗口」合并为「窗口与程序」。打开面板 / 设置 / 速记这些**不是步骤**，改用面板右键里的「常用功能 / LTools 功能」（见 §6），需要插进流程时用对应的普通步骤自己拼。
- **分类可以折叠，也可以一键全收 / 全展开**：点分类标题（带底色的分组条，箭头 + 名称 + 单元数）收起 / 展开这一组；左栏标题右侧的「全部展开 / 全部收起」一次处理所有分类（搜索时两个按钮置灰）。折叠状态是**全局记忆**（存 `configs/ui.json` 的 `ToolboxCollapsedGroups`）：换一个动作编辑、关掉重开都沿用上次的样子，不跟着动作走。搜索时分类一律展开（否则搜到了却被折叠挡住），清空搜索后恢复原来的折叠。
- 每个步骤可单独设置**延迟**（执行前等待，毫秒）与**失败策略**：继续下一步（默认）或中止动作。
- 右栏变量面板：名称 / 类型 / 默认值；步骤输出用到的新变量在保存时自动登记。变量只在本次运行内有效，不写盘、不跨运行。**列表 / 对象的默认值也能填**：列表每行一项（也可以逗号分隔），要带逗号或嵌套就写 JSON 数组；对象写 JSON。填错了会提示并拦住保存，不会悄悄变成空列表。
- 子动作是**可复用的步骤段**：设置 →「子动作库」管理全局子动作，变量标成「输入 / 本地 / 输出」，动作里用「调用子动作」从下拉选（「本动作 · …」和「全局 · …」都会列出来，不用记 id），输入参数直接按变量名填，输出按 `out` 映射写回，调用层数上限 8。
- 运行中按停止热键（与宏回放共用，默认 `Ctrl+F3`）可随时停止；同一时间只允许一个动作运行（单步动作可直接执行）。
- **试运行不用先保存**：编辑器底部「▶ 试运行」跑的就是你现在改的内容（克隆一份，不写盘），「▶ 从此行」从选中的**顶层**步骤开始；它会真的操作鼠标键盘，中途可以「■ 停止」。**运行选中步骤**：选中若干步骤（`Ctrl` / `Shift` 点选）后右键「运行选中的 N 步」（单行是「只运行这一步」），只跑这几步——选中的块和块里的子步骤一起选时取最外层（子步骤跟着块走）；选中的全是顶层步骤时未选中的会自动跳过，轨迹里的「第 N 行」仍与编辑器行号一致，选中里含分支步骤时压紧成临时动作（状态栏会注明「按临时动作编号」）。展开后左「运行轨迹」按步骤列出每一步（✓ / ✕ / ! / ■ + 耗时 + 写入的变量 / 错误），循环里的同一步骤只占一行并标 `×N`，右「变量」是运行结束时的快照。点轨迹行会跳到左侧对应步骤；失败时自动选中失败那一行。试运行与真实运行共用同一把互斥锁和停止热键，不会同时操作键鼠；关掉编辑器会顺手停掉还在跑的试运行。**试运行一定给提示**（成功 2.5 秒、失败常驻，和真实运行时看到的一致），所以想验证「失败卡片长什么样」时，直接加一个跑不通的步骤点「▶ 试运行」就行（例如「窗口操作」不填标题 / 类名）。
- **运行结果怎么提示**：失败一定留得住——卡片常驻（点一下关，下一次运行自动替换），标题带失败位置「第 3 行 › 否则 › 第 1 行」，红条 + 红边一眼能分辨；成功默认不打扰，可在设置 →「通用 → 运行提示」改成「成功也提示」；按停止会给一条「已停止 · N 步」。失败文案用的是**编辑器里的行号**（`第 3 行「提示弹窗」失败：缺少参数「内容」`），不是运行时步数——循环 / 分支跑多少轮都对得上。
- 动作只有一种结构（`Program` = 变量表 + 步骤）：**不做旧格式迁移**，旧版（v1）动作文件解析不了就是坏文件，重新建一个即可。

### 10.2 变量与模板

- 参数的**取值单元**里有：选中文本、剪贴板（纯文本 / HTML / RTF）、光标位置、日期时间、输入文本、截图、文字识别、找文字、读速记、找图、屏幕取色、窗口、进程、**列出文件夹、JSON、正则提取**、**剪贴板文件、剪贴板图片、选中的文件、资源管理器路径、临时文件路径、系统文件夹、图片信息、文件哈希**等；**变量名可以用中文**（如「名称」），文本里写 `${名称}` 引用
- **同名变量可以反复赋值**：再建一个「设置变量」填同一个名字就是覆盖。勾上「追加」就是 `a += 右值`：新值接在变量原来的文本后面，变量还不存在时当作空串。右值里的 `${a}` 取的是**追加前**的旧值，所以 `a += ${a}` 就是把 `a` 复制一份接在自己后面
- **每个参数三态**：默认「文本模板」写内容，用 `${变量}` 插入运行时值；切到「变量」就只填变量名（保留 found / number 等类型与属性）；切到「取值单元」则当场取一个值（可再嵌套）——选好后点「填参数…」补齐带 * 的必填项，提示行会列出还缺什么
- **窗口 / 进程不用手填**：点「从当前窗口选择…」列出当前可见窗口（标题 + 类名 + 进程），点「从运行中的进程选择…」列出运行中的进程（实例数 + 主窗口标题）；搜索、回车或双击即可回填。窗口条件默认只有一个「标题包含」输入框，类名精确匹配收在「高级」里（同名窗口分不清时才需要）；选窗口只回填标题，不会偷偷加一个看不见的类名过滤
- 编辑器里的下拉框打开时按真实视口校正位置，不会「一打开就跳过前几项」；下拉框收起时滚轮掠过它，滚的是所在页面，不会偷偷改掉选中值
- 变量**只在本次运行内有效**，不写盘、不跨运行；**没有内置变量**——要用剪贴板 / 选中文本 / 光标位置 / 日期时间，就在参数的「取值单元」里选一下，让它们变成你自己的变量。选中文本通过 UI Automation 读取，不模拟按键、不动剪贴板；循环下标用循环步骤的输出映射到变量，每轮开始写入当前下标（从 0 开始）
- 文本字段（发送文本、运行命令、鼠标坐标、比较右值等）支持 `${变量名}`；图像匹配结果带中心坐标与相似度，用 `${m.x}` / `${m.y}` / `${m.score}` / `${m.found}` 取（`${m}` 本身是 `x,y` 坐标文本，**没找到时为空**，是否找到请用 `${m.found}`）；`$$` 表示字面 `$`
- **变量面板会列出可用属性**：图像结果的 `.x` / `.y` / `.found` / `.score`、找文字结果的 `.x` / `.y` / `.found` / `.text`、速记的 `.title` / `.time` / `.path` / `.count`、命令结果的 `.exit` / `.err`、鼠标 / 光标 / 文字点击的 `.x` / `.y` 等都可以在 `${变量.属性}` 里取；没有该属性的变量取出来是空
- **动作结果可以存进变量**：参数对话框底部有「输出」区（只对能产生结果的单元显示），把输出映射到变量名，执行结果就写进变量，后面的步骤直接用 `${变量}` 引用。支持的动作与内容：
  - 启动程序 → 新进程 PID
  - 打开文件 / 文件夹 / 网址 → 实际打开的目标（相对路径已解析）
  - 运行命令 → `${变量}` 标准输出、`${变量.exit}` 退出码、`${变量.err}` 错误输出
  - 写入剪贴板 → 实际写入的文本
  - 鼠标操作 → 操作后的光标坐标（`${变量.x}` / `${变量.y}`）
  - 窗口操作 → 操作后的窗口矩形（`${变量}` = `x,y,w,h`，另有 `.x` / `.y` / `.w` / `.h`）；调整大小被应用夹住时给的是**实际**矩形
  - 文字点击 → 点击位置（`${变量}` = `x,y`，另有 `.x` / `.y` / `.found`）；找不到文字时按失败策略处理
  - 图片点击 → 点击位置（`${变量}` = `x,y`，另有 `.x` / `.y` / `.score` / `.found`）；找不到模板图时按失败策略处理
  - 写速记 → 速记文件路径（`${变量}` / `.path`），另有 `.title` / `.time`；文件落在数据根的 `速记\<分类>\`，与 CapsLock+N 的速记窗口同一个目录
  - 列出文件夹 → 路径**列表**（每项一个完整路径），另有 `.count` / `.truncated`；配「遍历列表」逐项处理，或先「列表操作 → 拼成文本」再交给命令
  - 剪贴板文件 / 选中的文件 / 资源管理器路径 → 同样是路径**列表**（`.count` / `.first` / `.names` / `.text`）；选中的文件另有 `.folder`（所在目录）。剪贴板文件还能写回去（`剪切` = 粘贴后移动）
  - 剪贴板图片 → 存下来的 **png 文件路径**（`.width` / `.height` 给尺寸）；把图片文件填进去就是写回剪贴板
  - 剪贴板历史（Win+V）→ 记录**列表**（每行「[文本] 开头几个字」/「[图片]」/「[文件]」，最新在前）、与它同序的 `.texts` 全文与 `.ids`；操作选「删除」时填 `.ids` 里的一条，**留空 = 删最新一条**。需要系统开启「剪贴板历史记录」，关着会直接说清去哪开
  - 清空剪贴板 → `.cleared` 是否清空成功；勾上「连历史一起清」时 `.count` 给出清掉了几条历史（不可恢复）
  - 系统文件夹 / 临时文件路径 → 目录或文件路径（临时路径**只生成路径，不创建文件**）
  - 图片信息 → `.width` / `.height` / `.format` / `.orientation`（EXIF 方向）/ `.exifDate`
  - 文件哈希 → 十六进制哈希（`.algorithm` / `.size`）；文件不存在时 `.found` 为假，不报错
  - 文件是否存在 → 除 `.exists` / `.isFile` / `.isFolder` / `.size` / `.modified` 外，还有 `.createTime` / `.isReadOnly` / `.isHidden` / `.isSystem`；目录另给顶层 `.fileCount` / `.totalSize`，`.lnk` 快捷方式给 `.lnkTarget`
  - JSON / 正则提取 → 结果列表（JSON 数组、正则全部命中），可直接给「遍历列表」；JSON 还能用「取值路径」（`a.b[0]`）直接取其中一段
  - 填了输出变量的「运行命令」会改为**后台捕获执行**（不显示窗口，按所选终端隐藏执行）：${变量} = 标准输出、${变量.exit} = 退出码、${变量.err} = 错误输出。命令结束才继续下一步；停止热键可以连同子进程一起结束，输出过长会截断到 20 万字符。留空表示不需要结果。这种模式下**「保持窗口」不生效**（没有窗口），编辑器会把该选项置灰并说明；「终端」仍然决定由哪个 shell 执行（CMD / Windows Terminal / 直接运行三种都落到 `cmd.exe`）
- 条件支持等于 / 不等于 / 包含 / 开头 / 结尾 / 正则 / 为空 / 数值比较 / 为真为假，以及按取值结果的专用判定（找到了、窗口在前台等）
- 条件可勾选**取反**，循环里用它表达「直到…为止」
- 配置类错误（变量未定义、模板图片缺失、正则写错）会直接中止动作，不会带着错配置继续跑

### 10.3 读取选中文本 / 选中的文件

- 优先用 **UI Automation** 的文本模式直接问前台控件「你选了什么」：**不模拟按键、不动剪贴板**，浏览器 / Office / Electron / WinUI / 标准 Win32 编辑框都支持
- 个别老控件没有 UIA 文本模式时，自动退回给焦点窗口发 `WM_COPY`（标准复制消息，仍不模拟按键），读回后**还原剪贴板全部格式**；等待时间（100–5000ms）作用于这条兜底路径
- 局限：目标应用没有暴露任何文本/复制能力时读不到；安全桌面（锁屏 / UAC）下不可用
- **选中的文件**（「选中的文件」单元）走另一条路：资源管理器用 `Shell.Application` 读当前目录与选中项，桌面用 UI Automation 读选中的图标——同样不模拟按键、不动剪贴板。拿不到（前台不是资源管理器 / 桌面）只是 `found = false`，不报错
- 第三方文件管理器（Total Commander / Directory Opus / 网盘客户端）不在 COM 的范围里：需要时打开参数「资源管理器之外用 Ctrl+C」，它会模拟一次 Ctrl+C 读剪贴板。这会临时占用剪贴板，所以**默认关闭**；用完会把原来的文本 / 文件列表还回去（原本为空时保留这次复制的结果）

### 10.4 屏幕图像与颜色

- 「文字识别」识别一张**图片**里的文字：图片来自「截图」步骤（把它的变量填进来，例如 `${截图}`；截图结果自带存好的 png，直接读那张图，不会重新截屏），也可以填 `${截图.file}` 或图片文件路径。识别结果按行作为文本存入变量。编辑器里可以选识别引擎：
  - **PP-OCRv6 快速**（默认）：6.1 MB 模型随安装包分发，开箱可用，单张约 0.4 秒；小字、数字、深色底明显更准
  - **系统 OCR**：Windows 自带的 `Windows.Media.Ocr`，零下载、十几毫秒出结果，内存占用最小；中文 / 英文取决于系统已安装的语言包（中文 Windows 默认有简体中文）。12–14px 中文、数字与标点容易认错
  - **PP-OCRv6 高精度**：29.8 MB 模型，在取值器里点「下载模型（29.8 MB）」按需下载，逐文件校验 SHA-256，存到数据根的 `ocr-models\`（升级覆盖程序不会丢），单张约 1.2 秒
  - 选过一次就记住：新建 OCR 步骤沿用上次的引擎（没选过时默认 PP-OCRv6 快速）；已经保存的步骤保留各自的引擎，不受影响
  - 引擎首次使用时加载（约 0.2 秒），之后跨步骤复用；空闲 5 分钟自动卸载，把内存还给系统
  - 同图基准（15 个场景：12–28px 中英文、深色底、灰字、代码、整屏页面）的平均字符错误率：系统 OCR **0.304**、系统 OCR 先放大 2× 0.155、PP-OCRv6 快速 **0.016**、高精度 **0.000**
  - 结果怎么用：`${变量}` 是识别出的文本（按行）；`${变量.score}` 是 0–1 的平均置信度；`${变量.found}` 表示识别到文字（PP-OCRv6 下要求至少一行置信度 ≥ 0.5，避免把噪声当成功）。识别不到文字时变量为空，可用「不为空」判断；填的是图片文件路径时，编辑器里的「▶ 测试这个取值」可以直接看识别结果（填变量时变量要到运行时才有值）
- 「截图找图」选一张模板图（框选截图存在数据根的 `resources\images\`，自己放进 `resources\user\`，都跟随备份），在屏幕上找它：可限定**前台窗口 / 整个屏幕 / 固定区域**，可设等待超时和轮询间隔
- 模板图不用去文件管理器里找：编辑器里点**「框选截图」**，LTools 会先把自己的窗口最小化（不用 Hide——隐藏会结束 `ShowDialog` 的模态循环，编辑器随后就成「僵尸窗口」）、冻结屏幕画面，然后：
  - **单击窗口 / 控件**：鼠标移上去用琥珀色框出光标下的元素（该区域不压暗），单击即选中；滚轮在「控件 → 容器 → 窗口」之间换层级（Win32 窗口树 + UI Automation，自绘界面里的按钮 / 输入框也能认）
  - **拖动自由框选**：边角会自动吸附到附近窗口 / 控件的边（8px 内），按住 **Ctrl** 临时关闭吸附
  - 松手后**不急着确定**：选区长出八个把手，可以拖边 / 拖角 / 整体挪，方向键逐像素微调（Shift 每次 10px）；确认栏贴在**选区下方、与右边缘对齐**（下方放不下时翻到选区上方），满意了点**「✓ 使用这块区域」**（或 Enter、双击选区）才存成 `resources\images\shot-时间戳.png`，同时把搜索区域设成刚框的那一块（目标位置会移动时改成「前台窗口」）
  - 选区外的遮罩是 **40% 黑**：比之前的 60% 轻，旁边要对齐的按钮 / 文字仍然看得清
- 「换图…」默认打开 `resources\user\`；选到别的目录的图片会**复制一份进来**（重名加序号），配置里存相对路径，备份换机后不会断链。两个目录分工明确：`images\` 是程序生成、按引用自动回收（只删 `shot-*`），`user\` 整个不参与回收，放自己的素材不会被误删
- 旁边有缩略图，**点缩略图或「预览」**可在编辑窗口里弹出大图（窗口内浮层，不新开顶层窗口）；点图、按 Esc 或点浮层外面即关，不会挡到 / 影响正在编辑的动作编辑器窗口。想换搜索范围点「框选区域…」直接框（同样是先框再微调），不必手填 x / y / w / h
- 匹配用 OpenCV 模板匹配，并会尝试常见 Windows 缩放比例（100% / 125% / 150% …）；模板在 100% 下截取、在 125% 的屏幕上也能命中
- 命中后可用「鼠标操作」点 `${m.x}` / `${m.y}`；「找到了 / 没找到」可作条件
- 找图结果有三个东西，分工不同：`${m}` 是命中位置 `x,y`（**没找到时为空**）；`${m.found}` 是 `true` / `false`；`${m.score}` 是 **0–1 的相似度**（1 = 与模板完全一致）。分数低于「最低相似度」（默认 0.85）就算没找到，但 `${m.score}` 仍会给出这次最像的分数，方便判断阈值定高还是定低（例如总在 0.78 左右，就说明该把阈值降到 0.75，或重新截一张更干净的模板）
- 「屏幕取色」读取指定坐标的像素并返回 `#RRGGBB`，条件里可用「颜色接近目标」（可设容差）判断界面状态；点「⌖ 吸管取点」在冻结画面上单击即可：坐标与目标色一起回填，带 8 倍放大镜，取到的是物理像素，多显示器与缩放都不偏
- 每个取值器底部都有**「▶ 测试这个取值」**：按当前设置立刻求值一次（找图最多等 5 秒），直接看到「找到 · 相似度 0.96 · 位置 820, 540」这类结果，不用整条流程跑完才知道对不对

### 10.5 需要人参与的步骤（截图 · 交互框选 / 提示弹窗 / 文本窗口 / 输入文本）

这三步都要在流程跑到那里时跟人打一次交道，但在流程里的作用并不相同：

- **截图**（左栏「取值」）：取一张屏幕截图交给流程，四种方式：
  - **交互框选**（默认）：LTools 让开、冻结屏幕，由你框一块（与「框选截图」同一套：单击窗口 / 控件、拖动吸附、方向键微调），确认后流程自动继续；拖动时按 `Shift` 锁正方形、`Ctrl+A` 选整屏、`P` 复制坐标，拖动中按 `Esc` 只放弃这一次拖动
  - **前台窗口**：直接截当前前台窗口的可见范围（不含窗口阴影边距）
  - **整个屏幕**：截整个虚拟桌面（多显示器时为所有屏幕的合集）
  - **固定区域 / 变量区域**：填 `x,y,w,h`，或引用一个区域变量（如 `${截图}`）——想「和上一张同一块区域再截一次」就用它

  结果同时给出区域和图片：
  - `${变量}` 是 `x,y,w,h`；`${变量.x}` / `${变量.y}` 左上角，`${变量.w}` / `${变量.h}` 尺寸，`${变量.cx}` / `${变量.cy}` 中心点（可直接填进「鼠标操作」的坐标），`${变量.rect}` 与 `${变量}` 相同
  - `${变量.file}` 是存下来的 png 路径（交给「文字识别」或「打开文件」，也可写进剪贴板、发送文本）
  - `${变量.found}` 是取到了没有：交互框选时按 Esc / 取消为 `false`，**取消不会中止流程**——后面接一个「如果 `${变量.found}` 为真」即可决定要不要继续
  - 图片存在 `resources\images\`：**本次运行期间一直可用**（`.file` 交给后续步骤、写进剪贴板、交给外部程序都读得到），**下一次运行开始时**自动清掉上一次留下的、没人引用的；启动与删除动作时也会清。编辑器里「▶ 测试」试截的图测完即删。反复运行不会越堆越多
  - 想「等画面变成某个样子再继续」时，把它放进循环里配合「跳出循环」
- **提示弹窗**（左栏「基础动作」）：在屏幕某个角弹一张卡片，**不阻塞流程**——下一步立刻继续，最多同时 4 张（超出挤掉最旧的）。正文支持 `${变量}`，标题可选；停留时间默认 4 秒（0 = 不自动关闭，点一下卡片就关）。位置默认「跟随设置」（设置 → 通用 → 运行提示里的默认落点），也可以这一步单独指定六个方向。「去重键」填同一个值时，后来的提示会**就地更新**前一条并显示 `×N`，循环里反复提示同一句话不会刷满屏幕。卡片**不抢焦点**：自动化正在别的窗口里打字时，提示出现也不会把输入带偏
- **输入文本**（左栏「取值」）：弹出输入框等你填一段文字，确定后存进变量；勾「多行输入」可写多行内容（Enter 换行、Ctrl+Enter 确定）。取消时变量为空、`${变量.found}` 为 `false`，同样**不会中止流程**
- **文本窗口**（左栏「界面」）：记事本式的大窗口，用来**看长内容**或**让人改完再读回**。三种方式：
  - **显示**：只读、置顶、不抢焦点（点进去仍能全选复制），**默认不阻塞**——流程继续，窗口留给你看；勾「等窗口关闭」才会等。同一「复用键」只开一个窗口、内容就地替换，勾「追加到末尾」还能当运行日志（循环里逐行追加）
  - **读取**：可编辑窗口，点「确定」或 `Ctrl+Enter` 返回内容；`Esc` / 关闭 = 取消（`${变量.found}` 为 `false`、内容为空），`${变量.changed}` 告诉你用户改没改预填内容。**等待期间按停止热键能中止并关窗**（不是模态对话框）
  - **关闭窗口**：按「复用键」关掉；留空 = 关掉全部文本窗口
  - **只读 / 可编辑一眼可辨**：标题栏徽标（🔒「只读」灰底 / ✎「可编辑」深底）+ 正文底色（只读偏灰、可编辑纯白）+ 底部按钮（只读只有「关闭」，可编辑是「取消 / 确定」）；只读没有文本光标、鼠标是箭头，但仍能全选复制
  - 内容里的列表按每行一项、对象按 JSON 展开；JSON / 对齐数据可勾「等宽字体」。窗口的位置尺寸会记住（最大化时记住还原后的矩形），拔显示器后会夹回可见区

「截图 · 交互框选」与「输入文本」都需要真人操作，所以取值器底部的「▶ 测试这个取值」对它们不可用（会提示只在流程运行时可用）；截图的其余三种方式可以就地测试。

「截图 → 文字识别」是最常见的两步组合：先框一块，下一步把 `${截图}` 填进「文字识别」的图片变量，就得到那块区域里的文字。

### 10.6 鼠标操作

- 动作类型「鼠标操作」：左键单击 / 双击 / 右键 / 中键 / 只移动光标 / 滚轮上下；坐标为**虚拟桌面物理像素**（与截图、图像识别同一坐标系，多显示器也一致），点「⌖ 拾取」在屏幕上点一下即可填入
- 坐标**留空表示当前光标位置**（滚轮通常不必填坐标）；坐标也支持 `${变量}`，所以「找图 → 点它」就是两步：设置变量（屏幕图像）→ 鼠标操作（坐标填 `${m.x}` / `${m.y}`）
- 运行流程期间 LTools 的快捷键、超级面板全部暂停，普通按键仍照常送到前台应用；结束后自动恢复

### 10.7 窗口操作

- 动作类型「窗口操作」（左栏「基础动作」、动作编辑器都有）：按窗口标题（包含匹配）找到窗口，再加一个可选类名（精确匹配）区分同名窗口，然后做一件事：
  - **切换到前台**：最小化的窗口先还原，再抢前台；被系统前台锁拒绝时会用 `AttachThreadInput` 兜底再试一次，之后轮询确认真的到了前台
  - **最大化 / 最小化 / 还原**：发命令后读回窗口状态（`IsZoomed` / `IsIconic`），没达到就算失败
  - **调整到指定大小**：填 `x, y, w, h`（虚拟桌面物理像素，与鼠标 / 截图同一坐标系）。可以点「在屏幕上框选…」直接框一块区域，或点「用目标窗口当前尺寸」把现在的矩形抄进四个框
- 目标窗口不用手抄标题：点「从当前窗口选择…」，从当前可见窗口里挑一个即可。匹配规则与条件里的「窗口」取值完全一致（标题包含 + 类名精确，命中最上面那个），所以「如果 窗口在前台」和「切换到前台」指的是同一个窗口
- **不假装成功**：切前台被拒（别的程序全屏、窗口在别的虚拟桌面、目标进程无响应）、最大化 / 最小化 / 还原没生效，都会报错并交给步骤的失败策略处理——不会出现「这一步成功了，下一步却往错误的窗口里打字」
- 调整大小是唯一的例外：应用可能限制最小尺寸、或自己拒绝这次调整。这时记一条运行日志并继续，输出变量给的是窗口**实际**的矩形，所以 `${变量.w}` / `${变量.h}` 永远可信
- 可靠性：切前台、最大化、最小化、还原都很稳；调整大小对普通桌面程序（记事本、浏览器、编辑器）可靠，UWP / 商店应用 / 强制全屏的游戏可能被夹住——这正是「读回实际值」而不是假定的原因

### 10.8 文字点击与图片点击

- 动作类型「文字点击」（左栏「基础动作」、超级面板、动作编辑器都有）：在指定区域里识别文字，找到要点的文字就点它——省掉「截图 → 文字识别 → 算坐标 → 鼠标操作」四步
- 动作类型「图片点击」做同一件事，目标换成模板图：复用「截图找图」的匹配（多缩放候选、最低相似度、可等待），找到就点它，也比「截图找图 → 鼠标操作」少一个节点
- 区域与「截图找图」同一套语义：**前台窗口**（默认，执行时取当时最前面的窗口）/ **整个屏幕** / **固定区域**（虚拟桌面物理像素，点「框选区域…」直接框）。区域越小识别越快、越不容易认错
- 文字按**包含**匹配，忽略大小写与词间空格：写「保存」能命中「保存并关闭」，写「Save As」也能命中「SaveAs」；多处出现时点**最上面**那个（同高取最左），点的是命中文字的外接矩形中心
- 图片按模板匹配，分数低于「最低相似度」就算没找到；框选截图时会顺手把搜索区域收紧到框内
- 点击方式：左键单击 / 双击 / 右键 / 中键 / 只移动光标；文字点击的目标文字支持 `${变量}`
- 识别引擎与「文字识别」相同（默认 PP-OCRv6 快速；系统 OCR 更快更省内存；高精度需先在「文字识别」取值器里下载一次）
- 「找不到时最多等」会反复重试（0 = 只找一次），适合「点完上一步，等按钮出现再点」。一直找不到就是这一步失败，**不会假装点过**；文字点击的报错里会列出区域内识别到的文字，图片点击的报错里带最高相似度
- 输出变量：文字点击存点击位置（`${变量}` / `.x` / `.y` / `.found`）；图片点击另带 `.score`
- **只查找、不点击**：取值器「找文字」（「设置变量」、如果条件、循环条件都能用）输出 `${变量}` = 实际命中的文字、`.x` / `.y` = 命中位置、`.found` = 是否找到；「截图找图」本来就是这样的取值器（`.x` / `.y` / `.found` / `.score`）。要「先判断有没有，再决定点不点 / 点哪儿」时用它们，不必为了判断先点一下

### 10.9 速记（写速记 / 读速记）

- **写速记**动作：正文必填，标题 / 分类可选，都支持 `${变量}`。标题留空就用正文第一行；分类留空 = 未分类，填了不存在的分类会自动创建。保存位置与 CapsLock+N 完全相同（数据根 `速记\<分类>\<日期> <标题>.txt`），写进去的速记马上能在速记窗口里看到
- **读速记**取值器：按分类 + 关键字取**最近修改的一条**。分类留空 / 「全部」= 所有分类；关键字匹配标题或正文（包含即可，忽略大小写），同样支持 `${变量}`
- 结果怎么用：`${变量}` = 正文；`.title` / `.time` = 标题与时间；`.path` = 文件路径（可直接交给「打开文件」）；`.count` = 匹配到的条数；`.found` = 有没有匹配。**没匹配到不是错误**：`found = false`、`count = 0`，用「找到了 / 没找到」判断即可
- 典型组合：`选中文本 → 写速记`（把选中内容存下来）；`剪贴板 → 写速记（分类=收集箱）`；`读速记（分类=收集箱）→ 发送文本`（把最近一条发出去）
- 速记属于用户资产：不参与模板截图那种「按引用回收」，只有你自己在速记窗口里删除才会消失；备份 / 换机时跟着数据根一起走

### 10.10 脚本：AutoHotkey v2

左栏「脚本」分类里的 **AutoHotkey 脚本** 用来在流程中间跑一段 AHK v2 代码。运行时**随包内置**（`runtime\autohotkey\AutoHotkey64.exe`，v2.0.31），不用先装 AutoHotkey；许可证和源码出处放在 `licenses\`。

- 参数框是**等宽代码编辑器**（Tab 缩进、双向滚动）。下方「检查语法」只做语法检查、**不执行**脚本，错误会在旁边用红字显示，行号按你写的代码算。
- 脚本内容**原样执行**，不做 `${变量}` 模板替换——所以代码里的 `${…}`、花括号、引号都按 AHK 语法理解。流程变量通过下面的函数进出，不要直接写 `${名字}`。
- 与流程交互的三个函数：

| 函数 | 作用 |
|---|---|
| `LT_Var("名字", "默认值")` | 读当前流程变量（文本）；变量不存在时返回默认值 |
| `LT_Set("结果", 值)` | 写回流程变量；后面的步骤用 `${结果}` 就能取到 |
| `LT_Print(文本)` | 往标准输出写一行（UTF-8），对应「标准输出」输出 |

```autohotkey
名字 := LT_Var("名字", "世界")
LT_Print("你好，" . 名字)
LT_Set("结果", 名字 . "！")
```

- 输出：`标准输出`（`LT_Print` 的内容）、`错误输出`、`退出码`、`成功`；`完整结果` 里还带上 `LT_Set` 写回的所有变量。`LT_Set` 写回的变量**不勾输出也能用**（直接写进运行变量）。
- **失败和普通步骤一样**：语法错误、运行时错误、超时都会让这一步失败，提示卡片 / 运行轨迹里带**你代码的行号**（例如 `第 3 行「AutoHotkey 脚本」失败：第 2 行：…`），不会再弹 AHK 自己的错误框。停止热键会连同脚本进程一起结束；失败前 `LT_Set` 写过的变量仍会保留，方便判断跑到哪一步。
- 「超时毫秒」默认 60000（0 = 不超时，上限 1 小时）。适合一次性脚本；要常驻的热键脚本请用「运行命令」。
- 「工作目录」是脚本进程的工作目录（AHK 的 `A_WorkingDir`）；脚本文件本身在临时目录里，所以 `A_ScriptDir` 指向临时目录，`#Include` 的相对路径也按那里解析——需要包含文件时写绝对路径。
- 别在脚本里用 `MsgBox` / `InputBox` 等阻塞窗口：它们会一直等到超时。流程里的提示请用「提示弹窗」单元。

## 11. 自定义指南

所有配置在程序目录下的 `configs/`（开发环境为仓库根），由应用自身读写；**首次保存才生成**，升级解压不会覆盖。每个文件一个域：

| 文件 | 内容 |
| --- | --- |
| `configs/settings.json` | 全局行为：CapsLock 开关、终端路径、鼠标速度、运行提示、提示位置、日志 |
| `configs/ui.json` | 界面状态：导航页、展开的分组、最近使用、OCR 偏好、编辑器折叠态（丢了不影响功能） |
| `configs/hotkeys.json` | 快捷键：预设组 + 「快捷键 → 动作」绑定 + 全局默认名单 |
| `configs/panel.json` | 超级面板：开关 / 长按阈值 / 场景与分组 / 尺寸 / 上次页 |
| `configs/floating.json` | 悬浮项偏好（悬浮项本身不落盘） |
| `configs/macros.json` | 宏设置 + 宏元数据（事件本体在 `macros/<id>.json`） |

动作不进配置文件，而是一个动作一个目录：`actions/<id>/action.json`（动作体）+ `actions/<id>/files/`（它自己的模板图 / 脚本）。删除动作时整个目录移入 `trash/<时间戳>/`（保留 30 天，可手工捞回），菜单 / 面板 / 悬浮里的引用当场清掉。

分域之后，界面上改一个开关只会重写对应的那一个文件（例如改通知策略只动 `settings.json`、记住导航页只动 `ui.json`），不会顺手把动作清单或别的域一起写一遍。

`configs/` 不存在时读取同目录的 `LTools.example.json` 作为初始模板（发布包只带示例）。**不做向后兼容**：旧版单文件 `LTools.json`、更早的 `configs/actions.json` / `configs/menus.json` 以及任何 `.migrated` 归档都不再读取——从旧版本升级请重新配置，或导入新格式备份（备份里就是 `configs/` + `actions/`）。格式为 **JSON**（枚举写成字符串，如 `"Mode": "trim"`）。

某个配置文件存在但无法解析（手改出错 / 旧格式）时，程序会**保留原文件**并备份为 `<文件名>.bad-时间戳`（每个文件只留最近 3 份），本次运行该域使用默认值且不会写回；设置页保存时会提示失败。修复或从备份恢复后再保存即可，不会再把动作和菜单洗成空。

建议用图形界面修改（**CapsLock+\**），保存后自动生效。手改配置时请先退出 LTools，并注意热键字段必须写成小写 canonical 形式（如 `ctrl+f2`、`f2`）。

### 11.1 主要字段

- **`Actions`**：全局动作池（存于 `actions/<id>/action.json`）。每个动作只有 `Id` / `Name` / `Icon` / `Program`——**没有 `Type`**：一个键鼠宏就是一个「1 步 · `input.macro`」的动作（步骤参数 `macroId` 指向 `macros/<id>.json`）：
  - `Program`：变量表 `variables`、步骤 `steps`、动作内子动作 `subActions`。步骤是「功能单元 + 参数」的 JSON（`unit` / `in` / `out` / `body` / `then` / `else`），单元与写法见 `docs/ACTION_SYSTEM.md`；文本参数支持 `${变量}`。
  - **不读旧格式**：`Type` 为 `launchApp` / `runCommand` / `sendText` / `internal` 这类 v1 类型名，或 `"Type": "macro"` 的旧宏动作，都已经不支持——启动时旧宏动作目录会整体移进 `trash/<时间戳>/legacy-macro/`（连同它的宏文件），其余读不了的动作按坏文件处理（备份成 `.bad-时间戳`，该动作不加载）。
  - 动作里引用的模板图优先在 `actions/<id>/files/` 下找（采纳草稿时整体搬进来，写 `files/x.png` 或裸文件名都行）；共享 / 历史图存 `resources/images/`（程序生成，按引用回收）或 `resources/user/`（用户素材，不自动删除）。宏事件本体存数据根 `macros/<id>.json`，动作里只放 `macroId`。
- **`SuperPanel`**：面板开关。`Enabled`（独立开关）、`LongPressThresholdMs`（长按阈值 100–800）。
- **`Panel`**：动作面板结构。`Preferences`（尺寸、视图选项、上次全局场景）、`Global`（全局场景与标签）、`Context`（上下文场景、`Common` 兜底分组）、`Blocked`（禁止弹出的进程）、`HintDismissed`（是否关掉未配置提示）。动作入口只存动作 Id；字段见 `docs/PANEL_REDESIGN.md`。
- **`Hotkeys`**：快捷键，落在 `configs/hotkeys.json`：
  - `Groups`：预设组列表，顺序 = 运行期匹配优先级。每组有 `Id` / `Name` / `Enabled` / `Bindings`
  - 每条绑定只有 `Chord`（规范化的小写组合键，如 `capslock+s`、`ctrl+shift+f9`）、`ActionId`、`Enabled`、`Note`，以及可选的 `Scope`（`inherit` / `all` / `whitelist` / `blacklist`）与 `Filter`（`Processes` / `Titles` / `Classes`）
  - `DefaultScope` + `DefaultFilter`：全局默认名单，绑定写 `inherit`（或不写 `Scope`）时跟随它
  - `SeedVersion`：预设播种版本；删掉的预置条目不会因为版本没变而被重新加回来
- **`Macros`**：键鼠宏：
  - `Enabled`：宏功能总开关
  - `RecordHotkey` / `PlaybackStopHotkey`：停止录制 / 停止回放或自动化流程的热键，**统一存小写**（默认 `ctrl+f2` / `ctrl+f3`）；界面显示为 `Ctrl+F2` / `Ctrl+F3`。也允许无修饰键，如 `f2`、`pause`、`printscreen`
  - `CountdownMs`：回放前倒计时默认值（0 = 立即回放）
  - `MouseSampleMs` / `MouseSamplePx`：鼠标移动按时间间隔 / 最小位移抽稀
  - `MaxEvents`：单个宏最大事件数（达到后自动停止录制）
  - `DefaultSpeed` / `Loops`：回放速度与循环次数的全局默认值（宏可单独覆盖）
  - `Items`：宏元数据（名称、时长、事件数、回放参数），由应用维护；事件本体在数据根 `macros/<id>.json`
- **`TerminalPaths`**：终端路径覆盖（如 `gitbash`）。
- **`CapsLockModifier`**：CapsLock 是否作快捷键修饰键（轻按发 Esc）；关闭后走原生大小写切换。
- **`EdgeWheelVolume` / `EdgeWheelVolumeEdge`**：屏幕边缘滚轮调音量的开关与边（`bottom` / `top` / `both`，默认 `bottom`）。
- **`LastNavPage`**：设置页上次所在页（界面记忆，无需手改）。`ToolboxCollapsedGroups` 是动作编辑器左栏已折叠的单元分类（全局记忆，换动作 / 重开都沿用）。
- **`RunNotice`**：动作运行结束后的提示策略——`off`（不提示）/ `onFailure`（只在失败时，默认）/ `always`（成功也提示）。失败提示是常驻卡片，点一下关。
- **`ToastPosition`**：「提示弹窗」步骤没指定位置时的默认落点：`bottomRight`（默认）/ `bottomLeft` / `bottomCenter` / `topRight` / `topLeft` / `topCenter`。
- **`Logging`**：运行日志（数据根下 `logs/ltools-yyyyMMdd.log`，已 gitignore）：
  - `Enabled`：是否记录（默认 `true`）
  - `Level`：`error` / `warn` / `info` / `debug`，默认 `info`。`info` 记录启动环境、动作与流程执行、设置变更、宏录制 / 回放和异常，不记录文本正文；`debug` 额外记录每一步流程、取值结果与变量值（可能含剪贴板 / 选中文本内容）
  - `RetentionDays`：保留天数（默认 14，`0` = 不自动清理）
  - 崩溃日志同样会镜像进运行日志；日志只写本机，不上传

宏事件文件与 `Macros.Items` 是一对一关系：删除宏动作会删除对应宏文件；启动时也会回收不被任何动作步骤引用的孤儿宏。不要手工编辑 `macros/*.json`，需要修改请重新录制。

### 11.2 设置

**CapsLock+\** 打开设置（内置 WPF 窗口，改完自动保存）：

- **通用**：CapsLock 修饰键 / 边缘滚轮音量（含算哪条边）两个开关、开机自启、运行提示（结束后是否提示 + 默认提示位置）
- **动作管理**：表格一行一个动作——名称后跟灰色摘要，再列类型与被哪个区 / 场景 / 分组引用；双击编辑，顶部可按名称 / 类型筛选；新建 / 编辑动作（三栏编辑器）、复制、删除。宏动作在这里显示为「宏」+ 时长 / 事件数
- **键鼠宏**：录制热键 / 停止回放热键、宏列表（改名、试放、**回放设置…**（每宏的倒计时 / 速度 / 循环，留空跟随默认）、重新录制、删除、打开宏目录）、回放默认值（倒计时 / 速度 / 循环）与高级采样参数
- **子动作库**：全局子动作的列表与增删改；子动作是可复用的步骤段，变量标成输入 / 本地 / 输出，动作里用「调用子动作」按名调用
- **快捷键**：左预设组 + 右热键表（组 / 条目增删改、启停、上下移；「添加快捷键…」录制组合键并选动作；底部「全局默认」折叠区配白 / 黑名单）。重复组合键标红，排在前面的那条生效
- **面板管理**（左栏下拉：常规 / 场景 / 禁止弹出）：常规页放开关、长按阈值、显示分组名 / 紧凑磁贴；场景页左侧是场景列表（全局场景 / 上下文程序场景 / 窗口子场景 / 通用区），右侧是选中场景的匹配条件（默认折叠成一行摘要，点开可填进程名、完整路径、窗口标题包含与类名）与常驻的动作管理（分组 + 磁贴）；禁止弹出页管理不弹面板的程序
- **终端路径**：终端程序路径覆盖
- **运行日志**：运行日志开关、记录级别（仅错误 / 常规 / 详细）、保留天数；一键打开日志文件夹、打开今天的日志或复制路径。排查「按了没反应 / 某步为什么失败」时先看这里
- **备份与恢复**：导出 / 导入 `.ltbak`
- 工作目录可通过「选择...」弹出现代文件夹选择器（带快速访问导航栏）选取

## 12. 资源目录与备份

### 12.1 资源目录 `resources\`

`LTools.exe` 同级会自动创建 `resources\`，用来放脚本、程序、素材。动作里可以**用相对路径**引用它：

- 「启动程序」的程序路径填 `resources\foo.bat`，工作目录留空（默认就是程序目录）
- 「运行命令」的命令填 `resources\foo.ps1`
- 「打开文件」/「打开文件夹」的路径同样支持 `resources\xxx`

浏览选择或保存动作时，如果选到 `resources\` 或 `速记\` 里面的路径，会自动存成相对路径。这样备份换到另一台电脑导入后，引用资源目录的动作照常工作。编辑器里「工作目录」旁有「资源目录」按钮，一键打开该目录。

找图模板另有两个约定子目录，分工是「谁生成、谁负责清」：

- `resources\images\` —— 程序生成的模板图（框选截图的 `shot-时间戳.png`、剪贴板图片）。启动时、删除动作时、每次流程运行开始时按引用回收（引用来自取值器「截图找图」、各种取值器条件，以及「图片点击」动作的模板图）：删了动作 / 换了模板的截图不会一直堆着
- `resources\user\` —— 用户自己的素材。文件选择器默认打开这里，选到外部图片会复制进来；**整个目录不参与任何自动删除**

数据根下另有几类运行目录，和用户资产分开：

| 目录 | 内容 | 生命周期 |
|---|---|---|
| `actions\<动作id>\files\` | 该动作独占的模板图 / 脚本 | 随动作删除 / 备份；内容与别的动作相同时用硬链接共享（不重复占空间）；没人引用的图在启动时移进 `trash\orphans\` |
| `cache\screenshots\` | 「截图」步骤的运行期输出 png | 下一次运行开始时 / 程序启动时整体清空，不进备份 |
| `trash\` | 删除的动作目录、孤儿图 | 保留 30 天，可手工捞回 |
| `staging\` | AI 暂存区草稿 | 随采纳 / 删除变化，进备份 |

程序目录下另有随包运行时 `runtime\autohotkey\`（AutoHotkey v2）与 `licenses\`（第三方许可证和源码出处）。它们随构建 / 发布一起拷贝，**不要**把用户脚本或素材放进去；更新 AHK 用 `tools\fetch-autohotkey.ps1`。

### 12.2 备份与恢复

设置（`CapsLock+\`）→「备份与恢复」：

- **导出**：生成一个 `.ltbak` 文件（本质是 zip），包含 `configs\`（配置）+ `actions\`（动作与各自的模板图）+ `macros\` + `staging\`，`resources\` 与 `速记\` 可勾选。打包哪些目录由内置白名单决定，`cache\`、`ai\`、`logs\`、`trash\` 永不进备份
- **导出单个动作**：面板磁贴 / 动作管理磁贴右键 →「导出动作…」生成 `.ltact`（一个动作目录：动作体 + 它自己的 `files\`），方便分享或单独备份
- **导入**：整体替换现有数据。替换前会先把旧的配置 / 目录改名成 `.bak-时间戳`，导入失败自动回滚

导入前会提示备份里有多少个可执行文件、以及哪些动作会引用到它们——**导入备份等于可能以管理员权限运行外来脚本，只导入你信任的来源**。

详细设计与测试用例见 [docs/RESOURCE_DIR_AND_BACKUP.md](docs/RESOURCE_DIR_AND_BACKUP.md)。
