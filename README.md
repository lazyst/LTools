> 📋 **版本历史**：查看 [CHANGELOG.md](CHANGELOG.md) 了解详细更新记录
> 📦 **v2.0.0**：C# / .NET 8 / WPF 重构版。AHK 原版已归档至 [`ahk-legacy`](https://github.com/lazyst/LTools/tree/ahk-legacy) 分支。

## 0. 前言

本项目受 [Capslock+](https://capslox.com/capslock-plus/) 启发，并借鉴了 vim 的很多键位。主要自用于 Win11 24H2，其他系统未测试。

v2.0.0 起由原 AutoHotkey v2 脚本重构为 **C# / .NET 8 / WPF** 桌面程序，功能行为与 AHK 版本一致，性能与可维护性更好。重构细节见 [docs/WPF_MIGRATION_PLAN.md](docs/WPF_MIGRATION_PLAN.md)。

## 1. 构建与运行

### 依赖

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)（Windows）
- Windows 10/11（托盘、全局钩子、WPF）

### 构建

```bash
# 开发构建（无清单，调试）
dotnet build

# 发布构建（带 requireAdministrator 清单，双击即提权）
dotnet build -c Release
# 或发布单文件
dotnet publish -c Release -r win-x64 --self-contained false
```

输出位于 `bin/Debug/net10.0-windows/LTools.exe`（或 `Release`）。双击即提权运行（`app.manifest` 已配置 `requireAdministrator`）。

> 全局键盘/鼠标钩子需管理员权限，故发布版带提权清单。开发调试时可用 `-p:NoWin32Manifest=true` 免提权快速启动。

## 2. 基本功能

### 2.1 CapsLock 重映射

- **CapsLock 单击（≤0.3s）**：发送 Esc 键
- **CapsLock 长按（≥0.3s）**：犹豫操作，不触发 Esc

### 2.2 CapsLock 状态管理

- 自动维持 CapsLock 关闭状态
- **Ctrl+CapsLock**：手动切换 CapsLock 状态

### 2.3 工具临时禁用

- **启用 → 禁用：CapsLock+Esc**（无论短按长按）
  - 禁用后所有 CapsLock 增强功能暂时失效，CapsLock 恢复原生大小写切换
- **禁用 → 启用：长按 CapsLock+Esc（≥300ms）**
- 禁用状态下短按 CapsLock（<300ms）：正常切换大小写

### 2.4 控制与调试

- **Ctrl+Alt+I**：显示调试信息

## 3. 实用小功能

### 3.1 文件重命名

- **CapsLock+左键**：重命名文件，无需选中再按快捷键或右键

### 3.2 放大镜

- **CapsLock+Tab**：放大镜
- **Ctrl+Alt+滚轮**：放大缩小

### 3.3 快速搜索

- **CapsLock+Q**：搜索选中的文本内容
  - 网址 → 直接打开
  - 磁盘绝对路径 → 打开该路径
  - 普通文本 → Bing 搜索
  - 无选中 → 不执行

## 4. 文本编辑增强

### 4.1 光标移动

- **CapsLock+A**：向左移动一个单词
- **CapsLock+G**：向右移动一个单词
- **CapsLock+S**：向左移动一个字符
- **CapsLock+F**：向右移动一个字符
- **CapsLock+E**：向上移动一行
- **CapsLock+D**：向下移动一行
- **CapsLock+W**：移动到行首
- **CapsLock+R**：移动到行尾
- **CapsLock+Alt+A**：移动到文件开头
- **CapsLock+Alt+G**：移动到文件末尾

### 4.2 文本选择

- **CapsLock+H**：向左选择一个单词
- **CapsLock+;**：向右选择一个单词
- **CapsLock+J**：向左选择一个字符
- **CapsLock+L**：向右选择一个字符
- **CapsLock+I**：向上选择一行
- **CapsLock+K**：向下选择一行
- **CapsLock+U**：选择到行首
- **CapsLock+O**：选择到行尾
- **CapsLock+Alt+H**：选择到文件开头
- **CapsLock+Alt+;**：选择到文件末尾

### 4.3 删除操作

- **CapsLock+<**：向左删除一个字符
- **CapsLock+>**：向右删除一个字符
- **CapsLock+M**：删除到行首
- **CapsLock+?**：删除到行尾
- **CapsLock+Alt+M**：删除到文件开头
- **CapsLock+Alt+?**：删除到文件末尾
- **CapsLock+Backspace**：删除整行

### 4.4 特殊操作

- **CapsLock+Z**：撤销
- **CapsLock+X**：剪切（独立剪切板）
- **CapsLock+C**：复制（独立剪切板）
- **CapsLock+V**：黏贴（独立剪切板，多格式备份/恢复）
- **CapsLock+B**：任务视图（Win+Tab）
- **CapsLock+Y**：重做
- **CapsLock+Enter**：在当前行末尾插入换行
- **CapsLock+RShift**：在当前行上方插入空行

### 4.5 括号输入快捷键

- **CapsLock+[**：输入 `{`
- **CapsLock+]**：输入 `}`
- **CapsLock+9**：输入 `(`（当第 9 组菜单为空时）
- **CapsLock+0**：输入 `)`（当第 10 组菜单为空时）
- **CapsLock+'**：输入 `'`

> 这些快捷键设计用于减少编程时频繁在 CapsLock 和 Shift 键之间切换

### 4.6 符号定位

- **CapsLock+P**：定位到对应的配对符号位置（再次长按 CapsLock 或 Esc 取消）
  - 英文标点：`()`、`[]`、`{}`、`<>`
  - 中文标点：`「」`、`『』`、`【】`、`《》`、`〈〉`、`（）`、`［］`、`｛｝`、`〔〕`、`〖〗`、`〘〙`、`〚〛`、`""`、`''`、`‹›`、`«»`

## 5. 窗口管理增强

### 5.1 窗口置顶

- **CapsLock+右键**：置顶/取消置顶光标所在窗口

### 5.2 音量调节

- **屏幕底部滚轮**：鼠标在屏幕底部边缘（5px 范围内）时，滚轮调节系统音量
  - 向上增大、向下减小（每次 ±2），无需按 CapsLock
  - 跟随工具全局启用/禁用（CapsLock+Esc）

## 6. 鼠标模式

通过 **CapsLock+空格** 进入鼠标模式，可用字母键完全控制鼠标。

### 6.1 进入/退出

- **CapsLock+空格**：进入/退出鼠标模式
- **Esc**：退出鼠标模式

### 6.2 移动（按住可持续移动，多键同按可斜向）

- **e**：向上　**d**：向下　**s**：向左　**f**：向右

### 6.3 速度调节

- **q**：提高速度（范围 1-20）
- **a**：降低速度（范围 1-20）
- 速度自动保存到配置文件，重启后保持

### 6.4 点击与滚轮

- **w**：左键点击　**r**：右键点击
- **k**：向上滚动　**j**：向下滚动　**h**：向左滚动　**l**：向右滚动

## 7. 速记功能

### 7.1 基本操作

- **CapsLock+N**：打开速记窗口
  - 快速记录笔记、想法或任何文本内容
  - 保存时自动添加时间戳记录创建时间
  - 保存后不关闭窗口，自动加载保存的文件内容进入编辑模式

### 7.2 查看已记速记

- 左列列表显示速记文件（标题、修改时间），支持搜索过滤（标题优先匹配，不命中才扫正文，300ms 防抖）
- **单击**列表项即载入内容到右列编辑区
- **右键**列表项（或 **Ctrl+Del**）删除选中的速记，需确认；删除的是列表条目本身，只有恰好是当前编辑中的那条才会清空编辑区

### 7.3 保存

- 默认保存：有标题（首行）以标题为文件名；无标题以时间戳为文件名
- 保存位置：程序目录下的 `速记/` 文件夹，按分类子目录组织
- **Ctrl+S**：保存当前速记

## 8. 快捷菜单系统

### 8.1 基本操作

- **CapsLock+数字键（1-0）**：显示对应的快捷菜单组
  - 每组可自定义名称和菜单项
  - 为空的菜单组（如 9、0）会发送对应的括号字符 `(` 或 `)`
  - 现代 UI：圆角窗口、阴影、淡入淡出

### 8.2 菜单操作

- 点击按钮执行对应操作
- 按数字键（1-9, 0）执行对应序号操作
- Esc 或"关闭"按钮或点击菜单外区域关闭

### 8.3 菜单项

菜单项引用全局动作池里的动作（`MenuGroups[].Items` 存动作 Id），不再直接写命令字符串：

- 在设置 →「CapsLock快捷菜单」编辑：重命名菜单组、增删菜单项、从动作池添加，或当场新建普通 / 组合动作
- 每个菜单项可以是任意动作类型（启动程序、运行命令、打开网址、发送文本、模拟按键、键鼠宏等）
- 运行命令仍可选终端（PowerShell 7/5、CMD、Git Bash、WSL Bash）与「保持窗口」
- 快捷菜单与超级面板共用同一套动作池：改一个动作，两处同时生效

### 8.4 帮助面板

- **CapsLock+` **：打开帮助面板（热键速查表）
  - 按分类展示所有热键及功能
  - 标题栏整条可拖动窗口
  - 关闭按钮左侧钉子按钮：点击可**钉住**面板，钉住后点击外部不再关闭（可正常点击穿透下层窗口），再次点击取消钉住
  - 再次按 `CapsLock+`` 或 Esc 或点击外部关闭（钉住时仅热键 / Esc / ✕ 可关闭）

## 9. 键鼠宏录制 / 回放

把一段真实的键鼠操作录下来，之后一键原样重放。

### 9.1 录制

- 录制入口在**键鼠宏动作编辑窗口**：选类型「键鼠宏」→ 点「● 录制新宏」，窗口最小化后立即开录（无倒计时、无确认框）
- `Ctrl+F2`（默认，可在同一面板改）是**停止录制热键**：录制开始时临时注册、结束立即注销；开始录制靠面板「● 录制新宏」按钮或托盘，不再有全局的开始录制热键
- 热键录入是**录制式**的：点击「录制热键 / 停止回放」输入框后直接按下组合键即可（Esc 取消，Tab 结束）；**录到有效组合立即生效并写盘**，不必再保存整个动作。也可点「手动选择…」用可视化列表挑键。录入期间键盘钩子会让路，不会误触发宏录制或 CapsLock 功能。输入框显示为 `Ctrl+F4`，配置文件仍统一存小写 `ctrl+f4`
- 「全局」标题右侧的**恢复默认**按钮把两个热键一起恢复为 `Ctrl+F2`（录制）/ `Ctrl+F3`（停止回放），同样立即生效并写盘
- 热键**不强制要求修饰键**：可以直接用 `F2`、`F8`、`Pause`、`PrintScreen`、`Insert`、`Home`、`End`、`PageUp/PageDown` 等不产生字符的键。字母 / 数字 / 空格 / 方向键等会干扰日常输入，单独使用会被拒绝并提示搭配 `Ctrl / Shift / Alt / Win`；无修饰键热键只在「完全没按修饰键」时触发，`Ctrl+F2` 不会误触发裸 `F2`
- **录制中热键一定能停**：开始录制时会把该热键临时注册到系统，录制结束立刻注销——即使低级钩子被系统摘掉、修饰键判定异常，按录制热键也能停下
- 停止后**自动保存并回到编辑窗口**，不弹命名框，自动命名「录制 MM-dd HH:mm:ss」（重新录制沿用原宏名）
  - 从超级面板新建的编辑器，录制期间面板只**临时隐藏**（不关闭——关闭 owner 会连带销毁编辑器），停止后自动显示回来
  - 回到窗口时会把编辑器真正抬到前台（与前台窗口共享输入队列后 `SetForegroundWindow`）；若前台锁仍拒绝，就临时置顶保证它一定出现在最上层，点一下窗口即恢复普通层级——不会出现「录完窗口不见、找不到、无法完成新建」
- 托盘也能开始录制（会自动生成动作）；停止方式任意：录制热键，或托盘菜单（录制中标题变为「■ 停止录制宏」）
- 刚开录 600ms 内的「停止」会被忽略：录制按钮被双击 / 鼠标抖动时不会出现「一点录制就说已停止」；真要停止，等一会儿再按一次即可
- 录制期间窗口顶部显示录制指示器（事件数 + 停止热键提示）
- 录制期间 LTools 进入**透明模式**：CapsLock 增强、快捷菜单、超级面板、底部滚轮音量、资源管理器重命名等全部暂停，录到的输入就是目标应用实际收到的输入；CapsLock 本身不录入也不生效

### 9.2 回放

- 回放通过「键鼠宏」动作触发（快捷菜单 / 超级面板），组合动作里也可以把宏当作步骤
- 录制完成后可在宏动作编辑面板点「▶ 试放本宏」立即预览：使用面板上**当前**的速度 / 循环 / 倒计时（不必先保存动作），不会修改宏与参数；试放时编辑器自动最小化并让开 LTools 浮层，结束后恢复窗口。无限循环时同样按停止回放热键停止
- **回放参数按宏独立**，都在键鼠宏动作编辑面板设置：速度倍率、循环次数（1–99）或「无限」、回放前倒计时；未单独设置时使用全局默认值
- 无限循环时按**可配置的停止回放热键**（默认 `Ctrl+F3`，在宏动作编辑面板的「全局」区修改）停止：只在回放期间临时注册，回放结束立即释放；若该组合键已被其他程序占用，系统热键注册失败也不影响回放——LTools 键盘钩子会先一步吞掉该组合键并停止宏（同时提示一次）
- 回放按录制时的真实时序注入键盘与鼠标事件；结束时强制释放所有按键与鼠标键，不会卡键
- 鼠标移动用 `SendInput` 绝对坐标注入（虚拟桌面），换了分辨率或显示器布局会按比例缩放，旧宏仍按原坐标回放
- 每轮按录制时长补足末尾静默后再开始下一轮
- 鼠标移动按「采样间隔 / 采样位移」抽稀，避免事件文件过大（这两个是全局录制参数，也在宏动作面板编辑）

### 9.3 宏文件与动作

**一个键鼠宏就是一个动作**，宏文件不需要也不提供手工管理：

- **录制即生成动作**：用动作编辑器、托盘录完一个宏，动作池会自动多出一个同名「键鼠宏」动作，直接可绑快捷菜单 / 超级面板
- 动作编辑器里的「键鼠宏」类型：新建只能点「● 录制新宏」当场录制（窗口自动最小化并立即开录，停止后自动保存并绑定）；编辑已有宏动作时显示宏信息，点「重新录制」覆盖同一个宏
- **删除宏动作 = 删除对应宏文件**：不再有「键鼠录制」页、宏列表或改名 / 复制 / 删除按钮；托盘也没有「宏管理…」
- 启动时会按引用回收宏文件：不被任何宏动作或组合步骤引用的 `macros/*.json` 与元数据会自动清理（仍被组合步骤引用的宏会保留，避免破坏现有组合动作）
- 宏文件存于数据根 `macros/<id>.json`，元数据（名称、时长、回放参数等）存于 `LTools.json` 的 `Macros.Items`；备份会一起打包
- 动作编辑器标题栏右侧有「普通动作 / 组合动作」分段切换，一眼可见、一点即换（组合动作编辑器用同一控件；编辑组合步骤时隐藏，防止嵌套组合）
- 组合动作左栏「基础动作 → 键鼠宏」：点它当场录一个新宏作为步骤。宏步骤只存宏 Id，事件本体仍在 `macros/` 下——单独把组合动作拷到没有该宏的机器上会失效（步骤行会标出「宏文件缺失」）

## 10. 自动化流程（组合动作）

组合动作不只是「按顺序跑几条动作」：可以插入条件分支、循环和变量，配合屏幕图像识别 / 取色 / 鼠标操作做轻量自动化。入口：设置 →「动作管理」新建 / 编辑组合动作，或在快捷菜单、超级面板里当场新建。

### 10.1 流程控制

- 左栏「流程」分组提供：设置变量、如果、循环、跳出循环、进入下一次循环、停止流程；「取值」分组提供剪贴板文本、选中文本、鼠标位置、日期时间、上一步的错误，点一下就把当前值存成变量（生成的仍是普通「设置变量」节点）
- 流程是**嵌套块**：`如果 … 否则 … 结束如果`、`循环 … 结束循环`，用缩进表示层级；**没有 goto**，重复执行用「循环 + 跳出 / 继续」表达
- 中间流程区拖行首把手排序；拖到目标行的上半 / 下半决定插在它之前还是之后；「否则 / 结束如果 / 结束循环」这些标记行本身就是插入点
- 每行可单独设置**延迟**（执行前等待，毫秒）与**失败策略**：继续下一步（默认）或中止组合
- 步骤行默认压成单行（延迟 / 失败策略排在右侧），窗口够宽时标题自动占满、不够时才折成两行；标题被截断时悬停可看全文。窗口可拖拽调整大小、可最小化 / 最大化（最小化后从任务栏恢复），**流程节点、动作编辑器、组合动作编辑器、动作池选择器都能最小化 / 最大化**（超级面板 / 帮助面板等浮层除外），最大化严格落在当前显示器工作区，不会盖住任务栏
- 编辑器右栏顶部是**变量面板**：只列你自己用「设置变量」「取值」创建的变量，没有内置变量，不会再出现「我没设置却有」的条目。组合动作里点一下复制 `${变量}`；流程节点窗口里点一下直接插入到最近编辑的输入框（变量名 / 循环次数 / 下标变量这类纯名字框除外）
- 运行中按停止热键（与宏回放共用，默认 `Ctrl+F3`）可随时停止；同一时间只允许一个自动化流程运行
- 旧版本的组合动作（只有线性步骤）在打开编辑器或运行时自动升级成新流程，保存后写回新格式

### 10.2 变量与模板

- 「设置变量」的右值可以是：文本 / 变量、选中文本、剪贴板、光标位置、日期时间、询问用户、截图找图、屏幕取色、窗口、进程；**变量名可以用中文**（如「名称」），文本里写 `${名称}` 引用
- **固定文本与变量合并成「文本 / 变量」一栏**：直接写文本，用 `${变量}` 插入运行时值；**整段只写 `${变量}` 时自动按变量处理**（保留 found / number 等属性），比较方式会随之切换，不需要先想「这是文本还是变量」
- **窗口 / 进程不用手填**：点「从当前窗口选择…」列出当前可见窗口（标题 + 类名 + 进程），点「从运行中的进程选择…」列出运行中的进程（实例数 + 主窗口标题）；搜索、回车或双击即可回填。窗口条件默认只有一个「标题包含」输入框，类名精确匹配收在「高级」里（同名窗口分不清时才需要）；选窗口只回填标题，不会偷偷加一个看不见的类名过滤
- 编辑器里的下拉框打开时按真实视口校正位置，不会「一打开就跳过前几项」；下拉框收起时滚轮掠过它，滚的是所在页面，不会偷偷改掉选中值
- 变量**只在本次运行内有效**，不写盘、不跨运行；**没有内置变量**——要用剪贴板 / 选中文本 / 光标位置 / 日期时间，就在左栏「取值」里点一下，让它们变成你自己的变量。选中文本通过 UI Automation 读取，不模拟按键、不动剪贴板；循环下标在「循环」节点里填一个「下标变量」名（如「序号」），每轮开始写入当前下标（从 0 开始）
- 文本字段（发送文本、运行命令、鼠标坐标、比较右值等）支持 `${变量名}`；图像匹配结果带中心坐标与相似度，用 `${m.x}` / `${m.y}` / `${m.score}` / `${m.found}` 取；`$$` 表示字面 `$`
- 条件支持等于 / 不等于 / 包含 / 开头 / 结尾 / 正则 / 为空 / 数值比较 / 为真为假，以及按取值方式的专用判定（图像找到了、颜色接近目标、窗口在前台、进程正在运行）
- 条件可勾选**取反**，也可把判断结果存回变量（「结果变量」），循环里用来累计状态
- 配置类错误（变量未定义、模板图片缺失、正则写错）会直接中止流程，不会带着错配置继续跑

### 10.3 读取选中文本

- 优先用 **UI Automation** 的文本模式直接问前台控件「你选了什么」：**不模拟按键、不动剪贴板**，浏览器 / Office / Electron / WinUI / 标准 Win32 编辑框都支持
- 个别老控件没有 UIA 文本模式时，自动退回给焦点窗口发 `WM_COPY`（标准复制消息，仍不模拟按键），读回后**还原剪贴板全部格式**；等待时间（100–5000ms）作用于这条兜底路径
- 局限：目标应用没有暴露任何文本/复制能力时读不到；安全桌面（锁屏 / UAC）下不可用

### 10.4 屏幕图像与颜色

- 「截图找图」选一张模板图（放在数据根的 `resources\images\`，跟随备份），在屏幕上找它：可限定**前台窗口 / 整个屏幕 / 固定区域**，可设等待超时和轮询间隔
- 模板图不用去文件管理器里找：编辑器里点**「框选截图」**，LTools 会先把自己的窗口最小化（不用 Hide——隐藏会结束 `ShowDialog` 的模态循环，编辑器随后就成「僵尸窗口」）、冻结屏幕画面，拖个框后**不急着确定**——选区长出八个把手，可以拖边 / 拖角 / 整体挪，方向键逐像素微调（Shift 每次 10px），满意了点**「✓ 使用这块区域」**（或 Enter、双击选区）才存成 `resources\images\shot-时间戳.png`，同时把搜索区域设成刚框的那一块（目标位置会移动时改成「前台窗口」）；确认栏在选区下方，选区贴近屏幕底部时自动挪到上方，不会挡住正在调的那条边
- 旁边有缩略图，**点缩略图或「预览」**可在编辑窗口里弹出大图（窗口内浮层，不新开顶层窗口）；点图、按 Esc 或点浮层外面即关，不会挡到 / 影响正在编辑的组合动作窗口。想换搜索范围点「框选区域…」直接框（同样是先框再微调），不必手填 x / y / w / h
- 匹配用 OpenCV 模板匹配，并会尝试常见 Windows 缩放比例（100% / 125% / 150% …）；模板在 100% 下截取、在 125% 的屏幕上也能命中
- 命中后可用「鼠标操作」点 `${m.x}` / `${m.y}`；「找到了 / 没找到」可作条件
- 「屏幕取色」读取指定坐标的像素并返回 `#RRGGBB`，条件里可用「颜色接近目标」（可设容差）判断界面状态；点「⌖ 吸管取点」在冻结画面上单击即可：坐标与目标色一起回填，带 8 倍放大镜，取到的是物理像素，多显示器与缩放都不偏
- 每个取值器底部都有**「▶ 测试这个取值」**：按当前设置立刻求值一次（找图最多等 5 秒），直接看到「找到 · 相似度 0.96 · 位置 820, 540」这类结果，不用整条流程跑完才知道对不对

### 10.5 鼠标操作

- 动作类型「鼠标操作」：左键单击 / 双击 / 右键 / 中键 / 只移动光标 / 滚轮上下；坐标为**虚拟桌面物理像素**（与截图、图像识别同一坐标系，多显示器也一致），点「⌖ 拾取」在屏幕上点一下即可填入
- 坐标**留空表示当前光标位置**（滚轮通常不必填坐标）；坐标也支持 `${变量}`，所以「找图 → 点它」就是两步：设置变量（屏幕图像）→ 鼠标操作（坐标填 `${m.x}` / `${m.y}`）
- 运行流程期间 LTools 的 CapsLock 手势、快捷菜单、超级面板、vim 热键全部暂停，普通按键仍照常送到前台应用；结束后自动恢复

## 11. 自定义指南

所有配置在程序目录下的 `LTools.json`（开发环境为仓库根），由应用自身读写；**首次保存才生成**，升级解压不会覆盖。文件不存在时回退读取同目录的 `LTools.example.json`。格式为 **JSON**（枚举写成字符串，如 `"Type": "runCommand"`），**不是**旧的 INI 分节格式。

建议用图形界面修改（**CapsLock+\**），保存后自动生效。手改配置时请先退出 LTools，并注意热键字段必须写成小写 canonical 形式（如 `ctrl+f2`、`f2`）。

### 11.1 主要字段

- **`Actions`**：全局动作池。每个动作有 `Id` / `Name` / `Icon` / `Type` 及类型专属字段，类型见 `Features/ActionTypes.cs`：`launchApp`、`openFile`、`openFolder`、`openUrl`、`runCommand`、`sendText`、`sendKeys`、`mouse`、`macro`、`internal`、`composite`。宏动作只用 `MacroId` 引用事件文件，事件本体不在配置里。
  - `mouse`：`X` / `Y`（虚拟桌面像素，可写 `${变量}`）、`MouseAction`（`click` / `doubleClick` / `rightClick` / `middleClick` / `move` / `wheelUp` / `wheelDown`）、`WheelDelta`。
  - `composite`：`Flow` 是嵌套流程（`action` / `set` / `if` / `loop` / `break` / `continue` / `stop`），旧配置的 `Steps` 会在打开编辑器或运行时自动迁移并清空。流程变量只在单次运行内有效；文本字段只支持 `${变量}`（没有内置值，取值请用左栏「取值」或「设置变量」），`$$` 表示字面 `$`。图像识别用 `Probe` 的 `image`（模板放 `resources/images/`），颜色用 `color`。
- **`SuperPanel`**：超级面板。`Enabled`（独立开关）、`LongPressThresholdMs`（长按阈值 100–800）、`Pages`（每页 16 槽，元素为动作 Id 或 `null`）、`LastPage`（上次停留的页）。
- **`MenuGroups`**：固定 10 组（下标 0–9 对应 `CapsLock+1`~`CapsLock+0`，`null` 表示空组）。每组含 `Enabled`、`Name`、`Items`（动作 Id 列表）。
- **`Macros`**：键鼠宏：
  - `Enabled`：宏功能总开关
  - `RecordHotkey` / `PlaybackStopHotkey`：停止录制 / 停止回放或自动化流程的热键，**统一存小写**（默认 `ctrl+f2` / `ctrl+f3`）；界面显示为 `Ctrl+F2` / `Ctrl+F3`。也允许无修饰键，如 `f2`、`pause`、`printscreen`
  - `CountdownMs`：回放前倒计时默认值（0 = 立即回放）
  - `MouseSampleMs` / `MouseSamplePx`：鼠标移动按时间间隔 / 最小位移抽稀
  - `MaxEvents`：单个宏最大事件数（达到后自动停止录制）
  - `DefaultSpeed` / `Loops`：回放速度与循环次数的全局默认值（宏可单独覆盖）
  - `Items`：宏元数据（名称、时长、事件数、回放参数），由应用维护；事件本体在数据根 `macros/<id>.json`
- **`TerminalPaths`**：终端路径覆盖（如 `gitbash`）。
- **`MouseModeSpeed`**：鼠标模式速度 1–20。
- **`CapsLockEnabled`**：CapsLock 增强总开关（与 `SuperPanel.Enabled` 相互独立）。
- **`LastNavPage`** / **`CompositeCollapsedGroups`**：设置页上次所在页、组合动作左栏的折叠状态（`basic` / `flow` / `internal` / `pool`，界面记忆，无需手改）。

宏事件文件与 `Macros.Items` 是一对一关系：删除宏动作会删除对应宏文件；启动时也会回收不被任何动作或组合步骤引用的孤儿宏。不要手工编辑 `macros/*.json`，需要修改请重新录制。

### 11.2 设置

**CapsLock+\** 打开设置（内置 WPF 窗口）：

- **重新加载**：从 `LTools.json` 重新载入配置
- **保存配置**：保存修改回 `LTools.json` 并自动应用
- **通用**：CapsLock 增强 / 超级面板开关、开机自启
- **动作管理**：新建 / 编辑普通动作与组合动作；「键鼠宏」类型在此录制并设置回放参数
- **CapsLock快捷菜单**：管理 10 个菜单组及菜单项（组名、启用 / 禁用、项增删、双击编辑）
- **超级面板**：页与 16 个槽位、长按阈值、钉住等
- **终端路径**：终端程序路径覆盖
- **备份与恢复**：导出 / 导入 `.ltbak`
- 工作目录可通过「选择...」弹出现代文件夹选择器（带快速访问导航栏）选取

## 12. 资源目录与备份

### 12.1 资源目录 `resources\`

`LTools.exe` 同级会自动创建 `resources\`，用来放脚本、程序、素材。动作里可以**用相对路径**引用它：

- 「启动程序」的程序路径填 `resources\foo.bat`，工作目录留空（默认就是程序目录）
- 「运行命令」的命令填 `resources\foo.ps1`
- 「打开文件」/「打开文件夹」的路径同样支持 `resources\xxx`

浏览选择或保存动作时，如果选到 `resources\` 或 `速记\` 里面的路径，会自动存成相对路径。这样备份换到另一台电脑导入后，引用资源目录的动作照常工作。编辑器里「工作目录」旁有「资源目录」按钮，一键打开该目录。

### 12.2 备份与恢复

设置（`CapsLock+\`）→「备份与恢复」：

- **导出**：生成一个 `.ltbak` 文件（本质是 zip），包含 `LTools.json` + `macros\` + `resources\` + `速记\`，后两者可勾选；宏文件随配置一起打包
- **导入**：整体替换现有数据。替换前会先把旧的配置 / 目录改名成 `.bak-时间戳`，导入失败自动回滚

导入前会提示备份里有多少个可执行文件、以及哪些动作会引用到它们——**导入备份等于可能以管理员权限运行外来脚本，只导入你信任的来源**。

详细设计与测试用例见 [docs/RESOURCE_DIR_AND_BACKUP.md](docs/RESOURCE_DIR_AND_BACKUP.md)。
